# 🎬 Видео курса

Видео **встраиваются прямо в сайт** — студент смотрит урок на странице дня, не уходя на YouTube.

## Как это работает

- Реестр видео — [videos.json](videos.json): день → ролики, месяц → плейлисты.
- Сайт показывает превью с кнопкой play. **Плеер (iframe) создаётся только по клику** — до этого страница не делает ни одного запроса к Google и грузится мгновенно.
- Используется домен `youtube-nocookie.com` (расширенный режим конфиденциальности).
- Если у дня своего ролика нет — показывается **видеокурс месяца** (плейлист).

## ⚖️ Почему embed, а не свои копии видео

Мы **не размещаем** копии чужих видео у себя — это нарушение авторских прав авторов (Созыкин, Яндекс и др.). Встраивание через плеер YouTube — законный механизм, который платформа предоставляет специально для этого: автор сам разрешает встраивание, сохраняет просмотры и авторство, а студент смотрит на нашем сайте.

Если захотите **свои** видео (записанные вами по [сценариям](../docs/video-scripts.md)) — их можно и залить на свой канал, и добавить сюда так же по ID.

## Как добавить видео

1. Найдите ролик на YouTube.
2. Скопируйте **ID** из адреса:
   - `youtube.com/watch?v=`**`fEQasuc9zvI`** → ID видео
   - `youtube.com/playlist?list=`**`PLtPJ9...`** → ID плейлиста
3. Добавьте запись в `videos.json`:

```json
{"d":5,"yt":"ID_ВИДЕО","t":"Название урока","a":"Автор","min":18}
```

Плейлист на весь месяц:
```json
{"months":[7],"yt":"ID_ПЛЕЙЛИСТА","t":"Docker с нуля","a":"Автор"}
```

4. Пересоберите данные сайта:
```bash
python site/build-data.py
```

| Поле | Значение |
|---|---|
| `d` | номер дня (1–270) |
| `months` | месяцы, к которым относится плейлист |
| `yt` | ID видео или плейлиста |
| `t` | название |
| `a` | автор/канал |
| `min` | длительность в минутах (для видео) |

К одному дню можно добавить несколько роликов — они покажутся списком.

## Текущее покрытие

Заполнены проверенные видео по темам: **сети** (курс Андрея Созыкина), **Linux/bash**, **Docker**, **Kubernetes**, плюс плейлисты Школы информационной безопасности Яндекса.

Остальные дни показывают видеокурс своего месяца. Покрытие пополняется — это хорошая задача для контрибьюторов (см. [CONTRIBUTING.md](../CONTRIBUTING.md)).

> ⚠️ Проверяйте, что видео **доступно для встраивания** (не приватное, встраивание не запрещено автором) и соответствует теме дня.

## Про ссылки «поиск на YouTube»

Часть дней в тексте курса ссылается на **поиск** YouTube по теме, а не на конкретный ролик. На сайте такие ссылки помечены подписью «поиск на YouTube» жёлтым — чтобы студент понимал: это тема для поиска, а не готовый урок. Заменять их на конкретные видео через этот реестр — самый полезный вклад в проект.
