# Портфолио-проекты (10 штук)

Работодатель верит не словам «я умею», а **тому, что ты сделал**. Эти 10 проектов на Python (твоя сильная сторона!) превращают навыки в осязаемое портфолио. Junior с 8–10 такими проектами на GitHub — редкость, тебя заметят.

**Правила хорошего проекта:**
- Чистый README: что делает, как запустить, скриншоты/примеры
- Понятный код с комментариями
- Реальная польза, не «hello world»
- Лицензия, `.gitignore`, requirements.txt
- В README — чему проект тебя научил

**Когда делать:** проекты привязаны к месяцам, но можно начинать раньше, если готов. Идеально — по одному в 2–3 недели, параллельно с обучением.

---

## 1. Мини-SIEM (после месяца 5/8)

**Что:** система, собирающая логи, ищущая подозрительные события и показывающая их в веб-интерфейсе.
**Стек:** Python + SQLite + Flask/FastAPI (веб-UI).
**Функции:**
- Приём и парсинг логов (syslog, auth.log, Windows)
- Правила детекта (напр. брутфорс, множественные 4625)
- Веб-дашборд с алертами
- Маппинг на MITRE ATT&CK
**Почему круто:** показывает и blue-team понимание, и умение писать софт. Флагман для SOC-резюме.

---

## 2. Log Analyzer (после месяца 8)

**Что:** инструмент анализа логов с привязкой к MITRE ATT&CK.
**Стек:** Python.
**Функции:**
- Парсинг syslog + Windows Event Logs
- Обнаружение паттернов атак
- Автоматический маппинг находок на техники ATT&CK
- Отчёт в Markdown/HTML
**Почему круто:** автоматизирует рутину аналитика.

---

## 3. Burp Suite Extension (после месяца 3)

**Что:** расширение для Burp, автоматизирующее проверку (напр. поиск IDOR или добавление своих пассивных проверок).
**Стек:** Python (Jython) или Java, [Montoya API](https://portswigger.net/burp/documentation/desktop/extend-burp/extensions/creating).
**Функции:**
- Кастомная проверка при проксировании трафика
- Подсветка подозрительных ответов
**Почему круто:** глубокое понимание веб-безопасности + инструментария.

---

## 4. Nmap Dashboard (после месяца 4)

**Что:** обёртка над Nmap с наглядным веб-отчётом.
**Стек:** Python + HTML/JS.
**Функции:**
- Запуск сканов, парсинг XML-вывода Nmap
- Визуализация: хосты, порты, сервисы, версии
- История сканов, диф между ними
**Почему круто:** полезный инструмент разведки, приятно показать.

---

## 5. Password Audit Tool (после месяца 2)

**Что:** инструмент аудита стойкости паролей/хэшей.
**Стек:** Python + обёртка над [Hashcat](https://hashcat.net/hashcat/)/[John](https://www.openwall.com/john/).
**Функции:**
- Определение типа хэша
- Запуск подбора по словарю/маске
- Отчёт: сколько паролей слабые, статистика
**Почему круто:** практический pentest-инструмент. **Только для своих/учебных хэшей.**

---

## 6. IOC Scanner (после месяца 8)

**Что:** сканер индикаторов компрометации по файлам/системе.
**Стек:** Python + [YARA](https://virustotal.github.io/yara/) + Sigma.
**Функции:**
- Проверка файлов YARA-правилами
- Поиск IOC (хэши, домены, IP) в логах
- Отчёт с найденными угрозами
**Почему круто:** blue-team + threat intel в одном.

---

## 7. Docker Security Scanner (после месяца 7)

**Что:** аудитор безопасности Docker-образов.
**Стек:** Python + [Trivy API](https://github.com/aquasecurity/trivy).
**Функции:**
- Скан образа на CVE
- Проверка Dockerfile на плохие практики (root, секреты)
- Единый отчёт с приоритизацией
**Почему круто:** DevSecOps + контейнеры, очень востребовано.

---

## 8. Cloud Misconfiguration Scanner (после месяца 7)

**Что:** сканер типовых мисконфигов в AWS.
**Стек:** Python + [boto3](https://boto3.amazonaws.com/v1/documentation/api/latest/index.html).
**Функции:**
- Поиск публичных S3-бакетов
- Проверка IAM на лишние права
- Проверка security groups (открытые порты)
- Отчёт по аналогии с Prowler (упрощённо)
**Почему круто:** cloud security — топ-дефицит на рынке.

---

## 9. Prompt Injection Scanner (после месяца 9)

**Что:** автопроверка LLM-приложения на типовые prompt-injection атаки.
**Стек:** Python.
**Функции:**
- Библиотека payload'ов (direct/indirect injection, jailbreak, prompt leak)
- Прогон против API чат-бота
- Оценка: какие атаки прошли, отчёт
**Почему круто:** **почти ни у кого из джунов такого нет.** Мгновенно выделяет тебя. Тема 2026.

---

## 10. Полный Pentest Report (после месяца 9)

**Что:** не код, а флагманский **документ** — отчёт уровня консалтинговой компании.
**Формат:** PDF/Markdown.
**Структура:**
- Executive Summary (для руководства, без жаргона)
- Scope (что тестировалось)
- Findings (каждая находка детально)
- CVSS (оценка критичности)
- MITRE ATT&CK / ATLAS mapping
- PoC (доказательства)
- Risk (влияние на бизнес)
- Remediation (как исправить)
**Почему круто:** показывает, что ты умеешь не только ломать, но и **общаться с бизнесом** — то, чего не хватает большинству технарей.

## 📊 Приоритет (если времени мало)

3. **Prompt Injection Scanner** (№9) — уникальный навык 2026

Остальные добавляй по мере сил. Даже 4 сильных проекта > 10 сырых.

## 💡 Как проекты работают на собеседовании

- В резюме: ссылка на GitHub + краткое описание каждого
- На собесе: «расскажите о проекте» → ты 5 минут уверенно рассказываешь про реальную работу
- Проект отвечает на вопрос работодателя «а сможет ли он что-то сделать сам?» — да, вот доказательства
- Python-инструменты показывают, что ты не просто «прошёл курсы», а **создаёшь**

> Один доведённый до ума проект с хорошим README стоит больше десяти сертификатов о прохождении курсов.
