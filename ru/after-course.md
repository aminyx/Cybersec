# 💼 После курса — профессии, зарплаты, что дальше

Куда идти после 270 дней. Для каждой профессии: чем занимаешься, зарплатный ориентир, что учить дальше, какие сертификаты.

> ⚠️ **Про зарплаты честно.** Цифры — грубый ориентир на 2026 год, они сильно зависят от региона, компании и удачи. Для Таджикистана/Средней Азии локальные IT-зарплаты заметно ниже российских; **реальный путь к высокому доходу — удалённая работа на российские и международные компании**. Это не финансовый совет, а обзор рынка. Диапазоны — «в среднем по рынку», а не гарантия.

---

## 🔵 Junior SOC Analyst (защита) — самый простой вход

**Чем занимаешься:** мониторишь события безопасности, разбираешь алерты, эскалируешь инциденты, работаешь в SIEM.

**Почему легче войти:** вакансий больше всего, охотно берут новичков и стажёров, часто есть внутреннее обучение.

**Зарплата (ориентир, РФ/удалёнка):** Junior ~60–120к ₽/мес → Middle ~150–250к ₽.

**Что учить дальше:** углублённый SIEM (конкретный вендор компании), threat hunting, detection engineering (месяц 8), автоматизация (SOAR).

**Сертификаты:** CompTIA Security+, BTL1 (Blue Team Level 1), позже — GCIA/GCIH.

**База в курсе:** месяцы 5, 8.

---

## 🔴 Junior Pentester (атака)

**Чем занимаешься:** ищешь уязвимости в системах/сетях/приложениях по заказу, пишешь отчёты с рекомендациями.

**Реальность:** интереснее звучит, но джунов берут реже — нужен уровень выше и часто портфолио/CTF-рейтинг. Отличный второй шаг после SOC.

**Зарплата (ориентир):** Junior ~80–150к ₽ → Middle ~180–300к ₽.

**Что учить дальше:** продвинутый AD, обход защит (evasion), C2-фреймворки, red team — см. [advanced-course.md](advanced-course.md).

**Сертификаты:** eJPT (старт) → OSCP (золотой стандарт, цель на 1–2 года) → OSEP/CRTP.

**База в курсе:** месяцы 2, 3, 4.

---

## 🟢 AppSec Engineer (безопасность приложений) — топ для тебя с Python

**Чем занимаешься:** ищешь уязвимости в коде и приложениях, встраиваешь безопасность в разработку, ревью кода, threat modeling.

**Почему тебе подходит:** твой Python-бэкграунд + веб (месяц 3) + DevSecOps (месяц 8) = прямой путь. Высоко ценится.

**Зарплата (ориентир):** Junior ~100–170к ₽ → Middle/Senior ~200–400к+ ₽.

**Что учить дальше:** SAST/DAST глубоко, secure code review, языки (Java/Go/JS), API security, threat modeling.

**Сертификаты:** нет одного «главного»; ценятся портфолио, bug bounty, CSSLP позже.

**База в курсе:** месяцы 3, 8.

---

## ☁️ Cloud Security Engineer — топ-дефицит рынка

**Чем занимаешься:** защищаешь облачную инфраструктуру (AWS/Azure/GCP), IAM, аудит конфигураций, cloud-native безопасность.

**Реальность:** огромный спрос, специалистов мало — зарплаты выше среднего. Обычно приходят после базового опыта.

**Зарплата (ориентир):** Junior ~120–200к ₽ → Middle/Senior ~250–450к+ ₽.

**Что учить дальше:** глубоко один провайдер, Kubernetes security, IaC (Terraform) security, cloud detection.

**Сертификаты:** AWS Security Specialty, AZ-500, CCSK/CKS (Kubernetes).

**База в курсе:** месяц 7.

---

## 🔧 DevSecOps Engineer

**Чем занимаешься:** встраиваешь безопасность в CI/CD, автоматизируешь сканирование, управляешь secrets, инфраструктурой как кодом.

**Почему востребовано:** компании внедряют DevSecOps массово, людей не хватает.

**Зарплата (ориентир):** Junior ~120–200к ₽ → Middle/Senior ~250–450к+ ₽.

**Что учить дальше:** Kubernetes, Terraform, облако, supply chain security, платформенная инженерия.

**Сертификаты:** CKS, облачные security-сертификаты.

**База в курсе:** месяцы 7, 8.

---

## 🎯 Detection Engineer

**Чем занимаешься:** пишешь и тюнишь правила обнаружения атак (Sigma/YARA), развиваешь покрытие по MITRE ATT&CK, detection-as-code.

**Реальность:** эволюция из SOC-аналитика, ценный и «инженерный» путь.

**Зарплата (ориентир):** ~150–300к ₽ и выше.

**Что учить дальше:** глубокий ATT&CK, threat intelligence, adversary emulation, конкретный SIEM/EDR.

**База в курсе:** месяц 8 (недели 30–31).

---

## 🤖 AI Security Engineer — профессия будущего (уже настоящего)

**Чем занимаешься:** тестируешь и защищаешь AI/LLM-системы: prompt injection, безопасность агентов/MCP, guardrails, AI red teaming.

**Реальность:** направление новое, специалистов почти нет — кто зайдёт рано, будет на острие. Пока чаще как специализация поверх AppSec/pentest, но спрос растёт стремительно.

**Зарплата (ориентир):** высокая из-за дефицита; сильно зависит от компании, часто на уровне senior AppSec и выше.

**Что учить дальше:** ML-основы, безопасность агентных систем, актуальные исследования (OWASP LLM, MITRE ATLAS), red teaming LLM.

**База в курсе:** месяц 9 — у тебя уже будет фора перед большинством.

## 🧭 Как выбрать

| Хочешь… | Тебе сюда | Вход |
|---|---|---|
| Быстрее устроиться | SOC Analyst | легко |
| Использовать Python | AppSec / AI Security | средне |
| Ломать системы | Pentester | сложнее |
| Высокий дефицитный навык | Cloud / AI Security | средне |
| Инженерия + автоматизация | DevSecOps / Detection | средне |

Совет: для **первой** работы бери самый лёгкий вход (SOC/AppSec), а специализацию углубляй уже в процессе. Перейти внутри профессии легко.

---

## 📈 Общий план роста

```
Junior (0–1.5 года) ──► Middle (1.5–4 года) ──► Senior (4+ лет)
   ↑ ты здесь           ↑ специализация          ↑ экспертиза + OSCP/эксперт-сертификаты
```

1. Устройся джуном (упорство важнее идеального резюме).
2. Первый сертификат за счёт/с помощью работодателя.
3. Углубляйся в одну нишу.
4. Через 1.5–2 года — тяжёлый сертификат (OSCP / профильный) и уровень уверенного специалиста.
5. Готов к продвинутому? → [advanced-course.md](advanced-course.md).

**Рынок ИБ голодный. Специалистов не хватает. С фундаментом, портфолио и упорством ты найдёшь место. Не останавливайся после курса — там начинается самое интересное.**
