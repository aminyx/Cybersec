# Словарь терминов — русский ↔ английский

Твоя главная сложность на старте — английские термины. Здесь собраны все, что встретятся за курс. Держи файл открытым и заглядывай, когда встретишь незнакомое слово. Термины сгруппированы по темам.

> Как учить: не зубри списком. Встретил термин в уроке → нашёл здесь → через 3–4 повторения в контексте он осядет сам.

## 🌐 Сети (месяц 1)

| Английский | Русский | Что это |
|---|---|---|
| Packet | Пакет | Кусочек данных, путешествующий по сети |
| Frame | Фрейм / кадр | Пакет на канальном уровне (L2) |
| Payload | Полезная нагрузка | Собственно данные внутри пакета |
| Header | Заголовок | Служебная информация в начале пакета |
| Protocol | Протокол | Правила общения (HTTP, TCP...) |
| Handshake | Рукопожатие | Установка соединения (SYN→SYN-ACK→ACK) |
| Subnet | Подсеть | Часть сети (например /24) |
| Gateway | Шлюз | Роутер, дверь в другую сеть |
| Router | Маршрутизатор | Пересылает пакеты между сетями (L3) |
| Switch | Коммутатор / свитч | Пересылает внутри сети (L2) |
| Port | Порт | «Дверь» сервиса (80 = HTTP) |
| Resolve | Разрешить (имя) | Превратить имя в IP через DNS |

## 🔤 40 слов технического английского

Если знаешь эти слова — читаешь 80% англоязычных материалов. Выучи их в первую очередь:

`enable / disable` (включить/выключить), `allow / deny` (разрешить/запретить), `request / response` (запрос/ответ), `source / destination` (источник/назначение), `input / output` (ввод/вывод), `default` (по умолчанию), `available` (доступный), `required` (требуется), `failed / success` (неудача/успех), `attempt` (попытка), `retrieve` (получить), `retrieve credentials` (получить учётные данные), `credentials` (учётные данные), `bypass` (обойти), `leverage` (использовать), `mitigate` (снизить риск), `patch` (заплатка/обновление), `disclose` (раскрыть), `remote / local` (удалённый/локальный), `arbitrary` (произвольный), `crafted` (специально сформированный), `malicious` (вредоносный), `legitimate` (легитимный/настоящий), `spoof` (подделать), `harden` (укрепить).

> Совет: заведи на телефоне [Anki](https://apps.ankiweb.net/) или простые карточки и добавляй по 5 новых слов в день из этого файла. За месяц — вся терминология твоя.
