# Месяц 9 — AI / LLM Security & MCP (Фаза 2, флагман)

**Цель месяца:** освоить самый горячий и дефицитный навык 2026–2027 — безопасность AI-систем. Почти каждая компания встроила GPT/Claude/Gemini/Copilot в продукты и внутренние процессы, а специалистов, умеющих это тестировать и защищать, почти нет. Джун с этим навыком выделяется мгновенно.

**Предпосылка:** месяцы 1–6 (особенно веб, месяц 3) + твой Python-бэкграунд (пригодится для автоматизации и AI-агентов).

**Главные ресурсы месяца:**
- 🤖 [OWASP Top 10 for LLM Applications](https://owasp.org/www-project-top-10-for-large-language-model-applications/)
- 🧪 [PortSwigger — Web LLM attacks](https://portswigger.net/web-security/llm-attacks) (бесплатные лабы!)
- 🧙 [Gandalf by Lakera](https://gandalf.lakera.ai/) — игра на prompt injection
- 📖 [MITRE ATLAS](https://atlas.mitre.org/) — ATT&CK для AI-систем
- 🔌 [Model Context Protocol (спецификация)](https://modelcontextprotocol.io/)

> Ты изучаешь это в удачный момент: индустрия только формирует практики, и глубокое понимание сейчас = большое преимущество на годы вперёд.

## Неделя 34 — Атаки на LLM-приложения

### День 248 — Indirect Prompt Injection
- 📺 **Теория (1,5 ч):** атака через данные, которые LLM прочитает (веб-страница, письмо, документ, тикет). Классика: скрытая инструкция на сайте, который резюмирует AI-агент.
- 💻 **Практика (2,5 ч):** Смоделируй: помести скрытую инструкцию в «документ», дай его LLM на обработку, посмотри, как она перехватывает поведение.
- ✍️ **Задание:** PoC косвенной инъекции через внешний контент.
- 🎯 **Проверь себя:** почему indirect injection опаснее direct для AI-агентов?

### День 249 — System Prompt Extraction & Leakage
- 📺 **Теория (1,5 ч):** извлечение системного промпта, утечка чувствительных данных из контекста.
- 💻 **Практика (2,5 ч):** На учебном чат-боте добейся выдачи его system prompt разными приёмами.
- ✍️ **Задание:** 3 разных способа вытащить system prompt.
- 🎯 **Проверь себя:** чем опасна утечка system prompt?

### День 250 — Jailbreak
- 📺 **Теория (1,5 ч):** методы обхода ограничений модели (роль-плей, кодировки, разбиение, «дедушкина» атака и др.) — **только для легального тестирования защит**.
- 💻 **Практика (2,5 ч):** На своей учебной LLM-обёртке проверяй устойчивость guardrails к обходам.
- ✍️ **Задание:** классификация методов jailbreak с примерами защиты от каждого.
- 🎯 **Проверь себя:** как guardrails пытаются ловить jailbreak и почему это гонка брони и снаряда?

### День 251 — Insecure Output Handling
- 📺 **Теория (1,5 ч):** вывод LLM попадает в HTML/SQL/shell → классические XSS/SQLi/RCE через ответ модели. Твой месяц 3 встречает AI.
- 💻 **Практика (2,5 ч):** Смоделируй: LLM генерирует ответ, который приложение неосторожно вставляет в страницу → XSS.
- ✍️ **Задание:** PoC XSS через небезопасную обработку вывода LLM.
- 🎯 **Проверь себя:** почему вывод LLM нельзя доверять как безопасный?

### День 252 — RAG и Vector DB Security
- 📺 **Теория (1,5 ч):** [RAG (Retrieval-Augmented Generation)](https://www.youtube.com/results?search_query=rag+retrieval+augmented+generation+простыми+словами), векторные БД, embedding. Атаки: отравление базы знаний, инъекция через документы, утечка данных между пользователями.
- 💻 **Практика (2,5 ч):** Разбери архитектуру RAG. Смоделируй отравление источника (indirect injection через проиндексированный документ).
- ✍️ **Задание:** объясни, как «отравить» RAG-базу.
- 🎯 **Проверь себя:** где в RAG-системе появляются новые точки атаки?

### День 253 — Data Poisoning и Model Supply Chain
- 📺 **Теория (1,5 ч):** отравление обучающих данных, риски скачивания моделей с [Hugging Face](https://huggingface.co/), небезопасная десериализация (pickle) моделей.

## Неделя 35 — MCP: безопасность агентов и инструментов

### День 255 — Что такое MCP и Tool Calling
- 📺 **Теория (2 ч):** [Model Context Protocol](https://modelcontextprotocol.io/) — как LLM подключается к инструментам и данным. Tool calling / function calling: модель вызывает внешние функции. Это то, что превращает чат-бота в **агента**, действующего в реальном мире.
- 💻 **Практика (1,5 ч):** Разбери спецификацию MCP: server, client, tools, resources, prompts.
- ✍️ **Задание:** схема: как LLM через MCP получает доступ к инструментам.
- 🎯 **Проверь себя:** чем агент с инструментами опаснее обычного чат-бота?

### День 256 — Модель угроз MCP/агентов
- 📺 **Теория (1,5 ч):** новые риски: excessive agency (слишком много прав у агента), tool injection, confused deputy, доступ агента к секретам/файлам/сети.
- 💻 **Практика (2 ч):** Разбери, как prompt injection + доступ к инструментам = агент выполняет вредные действия (удалить файлы, слить данные, сделать запрос).
- ✍️ **Задание:** модель угроз для AI-агента с 3 инструментами.
- 🎯 **Проверь себя:** что такое excessive agency и почему это в OWASP LLM Top 10?

### День 258 — Ломаем свой MCP-сервер
