# Журнал изменений

Все заметные изменения проекта фиксируются здесь.
Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — по [семантическому версионированию](VERSIONING.md).

Схема версий проекта:
- **MAJOR** (2.0.0) — обновление под стек нового года (напр. «редакция 2028»).
- **MINOR** (1.1.0) — новые лаборатории, модули, языки, крупные разделы.
- **PATCH** (1.0.1) — исправления ссылок, опечаток, мелкие правки.

### Добавлено
- **Вопросы по курсу — в GitHub Discussions** ([Q&A](https://github.com/aminyx/Cybersec/discussions/categories/q-a)): ссылки в README («Как начать»), FAQ на обоих
  языках и `docs/community-setup.md`. Спросить можно сразу, не дожидаясь своего Telegram/Discord.
- **Тесты переведены на таджикский** (`checks/tg/`): все 270. Механизм с откатом — если перевода дня нет, берётся русский.
- **Вопросы для собеседований на таджикском** (`tg/interview-questions.md`) — полный паритет языков достигнут.
- Реестр видео расширен: 24 дня с роликами, плейлисты на 7 месяцев (46 записей).
- Подсказка для дней повторения/резерва — раньше они выглядели «пустыми».
- Валидатор ловит новые `http://` ссылки (учебные — в белом списке).
- **Видео прямо на сайте** (`videos/`): плеер встроен в карточку дня — урок смотрится на странице,
  без ухода на YouTube. iframe создаётся только по клику (быстрая загрузка, никаких запросов к Google
  до нажатия), домен youtube-nocookie. Для дней без своего ролика — видеокурс месяца.
- **Проверка знаний на каждый день** (`checks/`): 270 тестов с вариантами и объяснениями.
  День нельзя отметить пройденным, пока тест не сдан — раньше прогресс был просто галочкой без подтверждения.
- CLI-проверка `checks/quiz.py` (день, диапазон, случайные вопросы, статистика) — для тех, кто учится по файлам.
- `scripts/shuffle_checks.py` — выравнивание позиций верных ответов.
- **ROADMAP.md** — roadmap разработки проекта (v1.1/v1.2/v2.0 + Mobile/LMS/AI Tutor и др.).
- **CI-валидация** репозитория ([.github/workflows/ci.yml](.github/workflows/ci.yml)) + валидатор `scripts/check_repo.py`
  (структура, ссылки, изображения, паритет ru/tg, тесты, актуальность data.js/STATS.md).
- **Docker dev-окружение**: `docker compose up` (Dockerfile, docker-compose.yml, requirements-dev.txt).
- **Wiki** (`docs/wiki/`): Home, How to Contribute, FAQ, Troubleshooting, Windows/Linux setup.
- **ADR** (`docs/adr/`): решения по статичному сайту, Markdown-источнику правды, localStorage, SHA-256 для CTF.

### Исправлено
- **Ссылки пропадали на сайте**: генератор данных вырезал markdown-ссылки, и студент видел
  «видео из плейлиста» без самого плейлиста. Теперь ссылки кликабельны + отдельный блок «Материалы дня».
- Для дней без собственных ссылок показываются ресурсы месяца — раньше там было просто «Теория 1,5 ч»
  без указания, куда идти.
- Верные ответы тестов были скучены на одной позиции (259 из 270 на B) — распределение выровнено.
- 61 ссылка вела в **поиск** YouTube, а выглядела как готовый урок — теперь честно помечена «поиск на YouTube».
- **Автопроверка проектов краснела на первом push**: шаг поиска секретов (`gitleaks-action`) строил
  диапазон от родителя первого коммита, а у корневого коммита родителя нет. `project-check.yml` теперь
  запускает сам gitleaks по всей истории — первый push проходит, и лицензия для организаций не нужна.
- **Мёртвая ссылка на Vulnlab** в продвинутом курсе (RU/TJ): домен `vulnlab.com` больше не отвечает —
  с 2025 года его лаборатории живут внутри Hack The Box. Ссылка ведёт на объявление HTB о том, где их искать.

- **Оценивание:** 6 практических экзаменов, 10 портфолио-проектов, чек-листы навыков.

- **Шаблоны:** pentest-отчёт, incident report, write-up, CVE, Sigma-правило, README проекта.
- **Вопросы для собеседований:** ~102 Q&A по трекам.

## Как заполнять этот файл

При каждом релизе:
1. Перенеси накопленное из `[Unreleased]` в новую версию с датой.
2. Сгруппируй: **Добавлено / Изменено / Исправлено / Удалено / Безопасность**.
3. Обнови файл [VERSION](VERSION) и, при необходимости, редакцию года.
4. Пройди [RELEASE_CHECKLIST.md](RELEASE_CHECKLIST.md).
