## Ҳафтаи 29 — DevSecOps: амният дар CI/CD

### Рӯзи 211 — DevSecOps чист
- 📺 **Назария (1,5 соат):** DevSecOps бо суханони содда. Shift-left, амният дар ҳар марҳилаи pipeline. [OWASP DevSecOps Guideline](https://owasp.org/www-project-devsecops-guideline/).
- 💻 **Амалия (2 соат):** CI/CD pipeline-и маъмулиро таҳлил кун. Репозиторий бо [GitHub Actions](https://docs.github.com/actions) соз.
- ✍️ **Супориш:** нақшаи pipeline бо нуқтаҳои назорати амният.
- 🎯 **Худро санҷ:** «shift left» дар амният чӣ маъно дорад?

### Рӯзи 212 — SAST: таҳлили статикии код
- 📺 **Назария (1,5 соат):** SAST, [Semgrep](https://semgrep.dev/), [CodeQL](https://codeql.github.com/). Ҷустуҷӯи осебпазириҳо дар код бе иҷро.
- 💻 **Амалия (2,5 соат):** [Semgrep](https://semgrep.dev/playground/)-ро дар коди қасдан осебпазир иҷро кун ([DVWA](https://github.com/digininja/DVWA) кодҳо ё [OWASP Juice Shop](https://github.com/juice-shop/juice-shop)). Ёфтаҳоро таҳлил кун.
- ✍️ **Супориш:** SQLi/инъексияи фармониро дар код тавассути Semgrep ёб.
- 🎯 **Худро санҷ:** SAST аз DAST чӣ фарқ дорад?

### Рӯзи 213 — SCA ва сканкунии вобастагиҳо
- 📺 **Назария (1,5 соат):** [Trivy](https://github.com/aquasecurity/trivy), [Snyk](https://snyk.io/), Dependabot, ҳамлаҳои supply chain.
- 💻 **Амалия (2 соат):** Вобастагиҳои лоиҳаро ба осебпазириҳо скан кун. [Dependency Review](https://docs.github.com/code-security) танзим кун.
- ✍️ **Супориш:** вобастагии осебпазирро дар лоиҳа ёб, ислоҳ пешниҳод кун.
- 🎯 **Худро санҷ:** ҳамлаи supply chain чист (мисол: xz, event-stream)?

### Рӯзи 214 — Secret Scanning
- 📺 **Назария (1,5 соат):** ихроҷи сирҳо дар таърихи git, [gitleaks](https://github.com/gitleaks/gitleaks), [TruffleHog](https://github.com/trufflesecurity/trufflehog).
- 💻 **Амалия (2 соат):** gitleaks-ро дар репозиторий иҷро кун (ҳатто худи куҳнаи худ!). Таҳлил кун, ки чӣ тавр сир дар таърих ҳатто баъди нест кардан зинда мемонад.
- ✍️ **Супориш:** сири «фаромӯшшуда»-ро дар таърихи git-и репои санҷишӣ ёб.
- 🎯 **Худро санҷ:** чаро `git rm` сирро аз таърих нест намекунад?

### Рӯзи 215 — Pipeline-и бехатар месозем

- ✍️ **Супориш (лоиҳаи хурд):** репозиторий бо CI/CD pipeline-и бехатар дар GitHub.
- 🎯 **Худро санҷ:** pipeline-и ту коди осебпазирро то продакшен бозмедорад?

### Рӯзи 216 — SBOM ва занҷири поставка

## Ҳафтаи 30 — Detection Engineering

### Рӯзи 218 — Аз таҳлилгар то муҳандиси детект
- 📺 **Назария (1,5 соат):** Detection Engineering чист. Фарқ: таҳлилгар алертҳоро мехонад, муҳандис қоидаҳоро *месозад*. Detection-as-code.
- 💻 **Амалия (2 соат):** Сохтори [Sigma-қоидаҳо](https://github.com/SigmaHQ/sigma)-ро амиқ омӯз. 5 қоидаи тайёрро таҳлил кун.
- ✍️ **Супориш:** Sigma-қоидаро аз рӯи сатрҳо таҳлил кун.
- 🎯 **Худро санҷ:** чаро Sigma формати «умумӣ»-и детект аст?

### Рӯзи 219 — Sysmon: телеметрияи Windows
- 📺 **Назария (1,5 соат):** [Sysmon](https://learn.microsoft.com/sysinternals/downloads/sysmon), конфиги [SwiftOnSecurity](https://github.com/SwiftOnSecurity/sysmon-config). Event ID: 1 (process), 3 (network), 11 (file), 22 (DNS).
- 💻 **Амалия (2,5 соат):** Sysmon-ро дар Windows-ВМ бо конфиги хуб насб кун. Амалро иҷро кун → онро дар логҳо ёб.
- ✍️ **Супориш:** 6 Event ID-и калидии Sysmon-ро бо он чӣ мегиранд муқоиса кун.
- 🎯 **Худро санҷ:** кадом Event ID оғози раванди шубҳанокро нишон медиҳад?

### Рӯзи 220 — Atomic Red Team: симулятсияи ҳамлаҳо
- 📺 **Назария (1 соат):** [Atomic Red Team](https://github.com/redcanaryco/atomic-red-team) — тестҳое ки техникаҳои MITRE ATT&CK-ро такрор мекунанд.
- 💻 **Амалия (3 соат):** Atomic-тестро (масалан T1059 — иҷрои фармонҳо) дар ВМ иҷро кун, осорро дар Sysmon/логҳо бубин.
- ✍️ **Супориш:** 3 atomic-тестро иҷро кун, телеметрияи ҳар якро сабт кун.
- 🎯 **Худро санҷ:** atomic-тестҳо чӣ тавр ба санҷиши детектҳо кӯмак мекунанд?

### Рӯзи 221 — Қоидаҳои детекти худро менависем
- 📺 **Назария (1,5 соат):** методология: техникаи ATT&CK → телеметрия → қоида → тест → танзим (мубориза бо false positive).
- 💻 **Амалия (2,5 соат):** Sigma-қоидаро дар яке аз ҳамлаҳое ки дар моҳҳои 2–4 кардӣ нависон (Kerberoasting, reverse shell, privesc). Бо atomic-тест санҷ.
- ✍️ **Супориш:** Sigma-қоидаи корӣ + далели кор кардан.
- 🎯 **Худро санҷ:** чӣ тавр false positive-ҳои қоидаи худро кам кардан?

### Рӯзи 222 — ELK / Elastic Security
- 📺 **Назария (1,5 соат):** [Elastic Stack](https://www.elastic.co/security) (Elasticsearch, Logstash, Kibana), қоидаҳои детект дар Elastic.
- 💻 **Амалия (2 соат):** Комнатаи THM оид ба Elastic/ELK. Дашборд соз, дархости-детект нависон.
- ✍️ **Супориш:** дашборди ошкори вурудҳои шубҳанок.
- 🎯 **Худро санҷ:** нақши ҳар компоненти ELK?

### Рӯзи 223 — Threat Hunting
- 📺 **Назария (1,5 соат):** методологияи threat hunting, гипотезаҳо, hunt дар асоси ATT&CK.
- 💻 **Амалия (2,5 соат):** Дар додаҳои таълимӣ hunt гузарон: гипотеза пешниҳод кун → аз рӯи логҳо санҷ → ёб/рад кун.
- ✍️ **Супориш:** ҳисобот оид ба як hunt.
- 🎯 **Худро санҷ:** hunting аз вокуниш ба алерт чӣ фарқ дорад?

### Рӯзи 224 — Такрори ҳафта
- 💻 **Амалия (3,5 соат):** Боз 2–3 қоидаи детект дар ҳамлаҳои худ нависон, санҷ.
- ✍️ **Супориш:** репозиторийи `detection-rules` дар GitHub бо Sigma-қоидаҳои ту.
- 🎯 **Худро санҷ:** маҷмӯаи детектҳои худӣ дорӣ?
