# 🎒 GitHub Student Pack ва хидматҳои ройгон

Ба донишҷӯён асбобҳои ба ҳазорон доллар — ройгон дастрасанд. Ин файл: чиро гирифтан ва **дар куҷои курс истифода бурдан**.

---

## ⚠️ Аввал — ростқавлона дар бораи дастрасӣ

**GitHub Student Pack** ва **JetBrains Student** тасдиқи он ки ту **донишҷӯи муассисаи расмӣ** ҳастӣ талаб мекунанд: email-и донишҷӯӣ ё сурати билети донишҷӯӣ/маълумотнома.

- **Агар донишҷӯ бошӣ** — расмӣ кун, ин қонунӣ ва ройгон аст.
- **Агар худат меомӯзӣ, бе муассиса** — эҳтимол санҷишро **намегузаронӣ**. Ҳуҷҷат сохта накун — ин зидди қоида ва ғайриқонунӣ аст. Хафа нашав: қариб ҳамаи хидматҳо **тарифҳои ройгон** доранд, ки курс пурра дар онҳо мегузарад.

## 🎯 Дар куҷо истифода бурдан

- **Моҳи 1–6:** GitHub (write-up-ҳо), PyCharm (скриптҳои Python), Codespaces (агар ПК суст бошад).
- **Моҳи 7 (Cloud):** 🔥 Azure for Students ($100) — амалияи воқеии абрӣ бе корти худат. DigitalOcean — VPS барои лаборатория.
- **Моҳи 8 (DevSecOps):** 🔥 GitHub Actions — сохтани pipeline-и бехатар (Semgrep + Trivy + gitleaks). CodeQL, Dependabot, Secret Scanning дар танзимоти репо ройгон.
- **Моҳи 9 (AI):** Copilot — фаҳмидани кори ёварони AI. Codespaces — иҷрои MCP-сервери худат.

## 🆓 Барои ҳама ройгон (бе донишҷӯӣ)

- **GitHub Free** — репозиторийҳо, Actions 2000 дақ/моҳ
- **GitHub Codespaces** — 60 соат/моҳ
- **PyCharm Community, VS Code** — IDE-ҳои ройгон
- **Oracle Cloud Free Tier** — VM-ҳои абадан ройгон (барои лаборатория хуб)
- **Ҳамаи платформаҳои таълимии курс** — TryHackMe, PortSwigger, Codeby Games ва ғ.

## ✅ Нақшаи амал

1. **Донишҷӯ?** → [GitHub Student Pack](https://education.github.com/pack) ва [JetBrains](https://www.jetbrains.com/community/education/)-ро имрӯз расмӣ кун.
2. **Худомӯз?** → GitHub-и оддӣ соз, PyCharm Community/VS Code гузор, Free Tier истифода бар.
3. Пеш аз моҳи 7 масъалаи кредити абриро ҳал кун.
4. **Ҳамеша billing-alert гузор** ва захираҳоро баъди лаб хомӯш кун — вагарна пул мегиранд.
