# 🛠️ Лоиҳаҳои портфолио (10 адад)

Корфармо на ба суханони «ман метавонам» бовар мекунад, балки ба **он чи ту сохтаӣ**. Ин 10 лоиҳа дар Python (ҷониби қавии ту!) маҳоратҳоро ба портфолиои ламсшаванда табдил медиҳанд. Junior бо 8–10 чунин лоиҳа дар GitHub нодир аст — туро мебинанд.

**Қоидаҳои лоиҳаи хуб:**
- README-и тоза: чӣ мекунад, чӣ тавр оғоз кардан, скриншотҳо/мисолҳо
- Коди фаҳмо бо шарҳҳо
- Фоидаи воқеӣ, на «hello world»
- Лицензия, `.gitignore`, requirements.txt
- Дар README — лоиҳа туро ба чӣ омӯхт

**Кай кардан:** лоиҳаҳо ба моҳҳо вобастаанд, вале агар тайёр бошӣ пештар оғоз кардан мумкин.

---

## 1. Мини-SIEM (баъд аз моҳи 5/8)
**Чӣ:** система, ки логҳоро ҷамъ мекунад, ҳодисаҳои шубҳанокро меёбад ва дар интерфейси веб нишон медиҳад.
**Стек:** Python + SQLite + Flask/FastAPI (веб-UI).
**Функсияҳо:** қабул ва таҳлили логҳо (syslog, auth.log, Windows); қоидаҳои детект (масалан брутфорс); дашборди веб бо алертҳо; мап ба MITRE ATT&CK.
**Чаро аъло:** ҳам фаҳмиши blue-team, ҳам маҳорати навиштани нармафзорро нишон медиҳад. Парчамбардор барои резюмеи SOC.

## 2. Log Analyzer (баъд аз моҳи 8)
**Чӣ:** асбоби таҳлили логҳо бо пайванд ба MITRE ATT&CK.
**Стек:** Python.
**Функсияҳо:** таҳлили syslog + Windows Event Logs; ошкори намунаҳои ҳамла; мапи худкор ба техникаҳои ATT&CK; ҳисобот дар Markdown/HTML.
**Чаро аъло:** рутинаи таҳлилгарро автоматизатсия мекунад.

## 3. Burp Suite Extension (баъд аз моҳи 3)
**Чӣ:** васеъкунӣ барои Burp, ки санҷишро автоматизатсия мекунад (масалан ҷустуҷӯи IDOR).
**Стек:** Python (Jython) ё Java, [Montoya API](https://portswigger.net/burp/documentation/desktop/extend-burp/extensions/creating).
**Функсияҳо:** санҷиши фармоишӣ ҳангоми проксикунии трафик; равшанкунии ҷавобҳои шубҳанок.
**Чаро аъло:** фаҳмиши амиқи амнияти веб + асбобсозӣ.

## 4. Nmap Dashboard (баъд аз моҳи 4)
**Чӣ:** обёрта дар болои Nmap бо ҳисоботи намоёни веб.
**Стек:** Python + HTML/JS.
**Функсияҳо:** оғози сканҳо, таҳлили XML-барориши Nmap; визуализатсия: хостҳо, портҳо, хидматҳо, версияҳо; таърихи сканҳо.
**Чаро аъло:** асбоби фоиданоки иктишоф, нишон додан хуш.

## 5. Password Audit Tool (баъд аз моҳи 2)
**Чӣ:** асбоби аудити устувории паролҳо/хешҳо.
**Стек:** Python + обёрта дар болои [Hashcat](https://hashcat.net/hashcat/)/[John](https://www.openwall.com/john/).
**Функсияҳо:** муайянкунии навъи хеш; оғози интихоб аз рӯи луғат/маска; ҳисобот: чанд парол суст, статистика.
**Чаро аъло:** асбоби амалии pentest. **Танҳо барои хешҳои худӣ/таълимӣ.**

## 6. IOC Scanner (баъд аз моҳи 8)
**Чӣ:** сканери индикаторҳои компрометатсия аз рӯи файлҳо/система.
**Стек:** Python + [YARA](https://virustotal.github.io/yara/) + Sigma.
**Функсияҳо:** санҷиши файлҳо бо YARA-қоидаҳо; ҷустуҷӯи IOC (хешҳо, доменҳо, IP) дар логҳо; ҳисобот бо таҳдидҳои ёфташуда.
**Чаро аъло:** blue-team + threat intel дар як.

## 7. Docker Security Scanner (баъд аз моҳи 7)
**Чӣ:** аудитори амнияти Docker-образҳо.
**Стек:** Python + [Trivy API](https://github.com/aquasecurity/trivy).
**Функсияҳо:** скани образ ба CVE; санҷиши Dockerfile ба амалҳои бад (root, сирҳо); ҳисоботи ягона бо афзалиятбандӣ.
**Чаро аъло:** DevSecOps + контейнерҳо, хеле серталаб.

## 8. Cloud Misconfiguration Scanner (баъд аз моҳи 7)
**Чӣ:** сканери мисконфигҳои маъмул дар AWS.
**Стек:** Python + [boto3](https://boto3.amazonaws.com/v1/documentation/api/latest/index.html).
**Функсияҳо:** ҷустуҷӯи бакетҳои оммавии S3; санҷиши IAM ба ҳуқуқи зиёдатӣ; санҷиши security groups (портҳои кушода); ҳисобот ба монанди Prowler (соддашуда).
**Чаро аъло:** cloud security — топ-камёбӣ дар бозор.

## 9. Prompt Injection Scanner (баъд аз моҳи 9)
**Чӣ:** санҷиши худкори барномаи LLM ба ҳамлаҳои маъмули prompt-injection.
**Стек:** Python.
**Функсияҳо:** китобхонаи payload-ҳо (direct/indirect injection, jailbreak, prompt leak); иҷро зидди API-и чат-бот; баҳо: кадом ҳамлаҳо гузаштанд, ҳисобот.
**Чаро аъло:** **қариб дар ҳеҷ кас аз junior-ҳо чунин нест.** Фавран туро фарқ мекунад. Мавзӯи 2026.

## 10. Pentest Report-и пурра (баъд аз моҳи 9)
**Чӣ:** на код, балки **ҳуҷҷати** парчамбардор — ҳисоботи сатҳи ширкати консалтингӣ.
**Формат:** PDF/Markdown.
**Сохтор:** Executive Summary; Scope; Findings; CVSS; MITRE ATT&CK / ATLAS mapping; PoC; Risk; Remediation.
**Чаро аъло:** нишон медиҳад, ки ту на танҳо шикаста метавонӣ, балки бо тиҷорат **муошират** карда метавонӣ — он чи аксари техникҳо надоранд.
