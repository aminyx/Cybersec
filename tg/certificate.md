# 🎓 Сертификати хатм

Баъд аз гузаштани ҳамаи 270 рӯз, имтиҳонҳо ва лоиҳаҳо, ту ба худ **сертификати хатм** месозӣ — PDF-и зебо барои портфолио, LinkedIn ва GitHub.

---

## ⚠️ Ин чӣ гуна сертификат аст (ростқавлона)

Ин **сертификати худомӯзӣ** аст, на сертификати аккредитшудаи соҳавӣ (ба монанди Security+ ё OSCP). Он ҳамчун ҳуҷҷати расмӣ дар назди корфармо валидатсия **намешавад**.

**Вале ҳамчун артефакти портфолио фоиданок аст:**
- Ба анҷомрасонӣ ва интизомро нишон медиҳад (270 рӯз — ин ҷиддӣ аст)
- Дар репозиторийи GitHub-и курс ва дар LinkedIn зебо ба назар мерасад
- Бо **далелҳои воқеӣ** тақвият дода шудааст: write-up-ҳо, лоиҳаҳо, ҳисоботҳои имтиҳонҳо

Арзиши воқеиро на худи PDF, балки **он чи дар паси он аст** медиҳад — портфолиое ки ҷамъ кардӣ. Сертификатҳои расмӣ (Security+, eJPT, OSCP)-ро алоҳида супор, онҳо дар [after-course.md](after-course.md) ҳастанд.

---

## 📋 Шартҳои додан (ба худ)

Вақте соз, ки чек-листи финалиро аз [checklists.md](checklists.md) ростқавлона пӯшидӣ:
- ✅ Ҳамаи 11 нишони моҳона
- ✅ Ҳамаи 6 имтиҳон
- ✅ Ҳадди ақал 4 лоиҳа (беҳтараш 10)
- ✅ Ҳадди ақал 1 мақола
- ✅ GitHub-портфолиои таҳияшуда

## 🖨️ Чӣ тавр PDF сохтан

Скрипти тайёр ҳаст: [`../assets/generate_certificate.py`](../assets/generate_certificate.py).

**Қадами 1 — вобастагиро насб кун:**
```bash
pip install fpdf2
```

**Қадами 2 — бо номи худ иҷро кун:**
```bash
python assets/generate_certificate.py --name "Номи Ту" --date "2027-04-25"
```

Ба таври ихтиёрӣ статистикаро нишон додан мумкин:
```bash
python assets/generate_certificate.py --name "Номи Ту" --date "2027-04-25" --machines 45 --projects 10 --writeups 60
```

**Қадами 3** — `certificate.pdf`-ро дар паҳлӯи скрипт мегирӣ. Тайёр 🎉

## 💡 Чӣ тавр истифода бурдан

- `certificate.pdf`-ро дар решаи репозиторийи GitHub-и курс гузор.
- Ба LinkedIn (бахши «Лицензияҳо ва сертификатҳо») бо ишора, ки ин self-study completion аст, илова кун.
- Дар резюме — **на** ҳамчун сертификати расмӣ, балки дар бахши «таълим/лоиҳаҳо» бо пайванд ба портфолио.
- Дар мусоҳиба муҳимтарин на PDF, балки он аст, ки ту лоиҳаҳо ва таҳлилҳоятро **нишон дода ва нақл карда метавонӣ**.

**То ин ҷо расидӣ — ту дар top-5%-и онҳое ки «ҳам мехостанд ба ИБ дароянд». Ифтихор кун ва наист.** 🚀
