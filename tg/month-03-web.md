# Моҳи 3 — Осебпазириҳои web (нони асосӣ)

**Мақсади моҳ:** амиқ азхудкунии амнияти барномаҳои веб — дар он ҷо бештарин осебпазириҳо, ҷойҳои корӣ ва bug bounty ҳастанд. Дар охири моҳ ту SQLi, XSS, IDOR ва дигар осебпазириҳои OWASP Top 10-ро меёбӣ ва эксплуатация мекунӣ, дар Burp Suite озод кор мекунӣ.

**Захираҳои асосии моҳ:**
- 🥇 [PortSwigger Web Security Academy](https://portswigger.net/web-security) — стандарти тиллоӣ, ройгон, садҳо лаб
- 🔧 [Burp Suite Community](https://portswigger.net/burp/communitydownload) — асбоби асосии амнияти веб
- 🎯 [OWASP Top 10](https://owasp.org/www-project-top-ten/) — харитаи осебпазириҳои асосӣ
- 💻 [DVWA](https://github.com/digininja/DVWA) ва [Codeby Games](https://codeby.games) — амалия

> Аз ин моҳ маводҳои зиёд бо забони англисӣ ҳастанд. Субтитр фаъол кун, истилоҳотро нависон — онҳо ҳамагӣ ~500-тоянд. Истилоҳотро ту аллакай аз моҳҳои 1–2 медонӣ, аз он чи фикр мекунӣ осонтар мешавад.

## Ҳафтаи 9 — Асосҳои веб ва Burp Suite

### Рӯзи 61 — Барномаи веб чӣ гуна сохта шудааст
- 📺 **Назария (1,5 соат):** Барномаи веб чӣ тавр кор мекунад. Муштарӣ (client), сервер, пойгоҳи додаҳо (БД), API, кукиҳо, сессияҳо.
- 💻 **Амалия (2 соат):** [DVWA](https://github.com/digininja/DVWA)-ро дар Kali насб кун (ё дохилии Metasploitable-ро истифода бар). Дар браузер кушо, аз назар гузарон.
- ✍️ **Супориш:** нақша каш: браузер → дархости HTTP → сервер → БД → ҷавоб.
- 🎯 **Худро санҷ:** сессия ва куки чист, барои чӣ лозиманд?

### Рӯзи 62 — HTTP чуқур: дархостҳо, методҳо, кодҳо
- 📺 **Назария (1,5 соат):** методҳо (GET, POST, PUT, DELETE), сарлавҳаҳо (headers), кодҳои ҷавоб (200, 301, 403, 500), кукиҳо.
- 💻 **Амалия (2 соат):** Дар [DevTools-и браузер](https://www.youtube.com/results?search_query=devtools+вкладка+network) (F12 → Network) дархостҳои воқеиро таҳлил кун. Сарлавҳаҳо, кукиҳо, баданро бубин.
- ✍️ **Супориш:** ҷадвали кодҳои ҷавоби HTTP (ҳадди ақал 12) ва маънои ҳар як.
- 🎯 **Худро санҷ:** 401 аз 403, 301 аз 302 чӣ фарқ дорад?

### Рӯзи 63 — Burp Suite: гирифтан ва такрори дархостҳо
- 📺 **Назария (1,5 соат):** Burp Suite барои навомӯзон. Proxy, Intercept, Repeater, Intruder.
- 💻 **Амалия (2 соат):** [Burp Community](https://portswigger.net/burp/communitydownload)-ро насб кун, браузерро ба прокси Burp танзим кун. Дархостро гир, таҳрир кун, ба Repeater фирист.
- ✍️ **Супориш:** дархости логинро дар DVWA гир, параметрро тағйир деҳ, аз нав фирист.
- 🎯 **Худро санҷ:** Repeater барои чӣ лозим аст ва аз Intruder чӣ фарқ дорад?

### Рӯзи 64 — PortSwigger Academy: оғоз
- 📺 **Назария (30 дақ):** дар [PortSwigger Academy](https://portswigger.net/web-security) аккаунт соз, бифаҳм лабҳо чӣ тавр оғоз мешаванд.
- 💻 **Амалия (3,5 соат):** Лабҳои муқаддимавӣ + мавзӯи [«SQL injection»](https://portswigger.net/web-security/sql-injection)-ро оғоз кун — назария ва аввалин 2 лаб.
- ✍️ **Супориш:** конспект: SQL-инъекция чист ва чаро ба вуҷуд меояд.
- 🎯 **Худро санҷ:** чаро ҳамроҳкунии вуруди корбар ба дархости SQL хатарнок аст?

### Рӯзи 65 — SQL-инъексияҳо: асосҳо
- 📺 **Назария (1,5 соат):** SQL-инъексияҳо бо суханони содда. Чӣ тавр `' OR 1=1--` дархостро мешиканад.
- 💻 **Амалия (2 соат):** PortSwigger — лабҳои SQLi (гузаштан аз логин, гирифтани додаҳо тавассути UNION).
- ✍️ **Супориш:** write-up-и як лаби SQLi бо шарҳи payload.
- 🎯 **Худро санҷ:** `' OR '1'='1` дар шакли логин чӣ кор мекунад?

### Рӯзи 66 — SQL-инъексияҳо: UNION ва гирифтани додаҳо
- 📺 **Назария (1,5 соат):** UNION-based SQLi, муайян кардани шумораи сутунҳо, кашидани ҷадвалҳо аз information_schema.
- 💻 **Амалия (2,5 соат):** PortSwigger — лабҳои UNION-based. Версияи БД, номҳои ҷадвалҳо, паролҳои корбаронро гир.
- ✍️ **Супориш:** маълумоти вурудро аз БД-и таълимӣ тавассути UNION гир, қадамҳоро нависон.
- 🎯 **Худро санҷ:** чӣ тавр шумораи сутунҳоро дар дархост муайян кардан?

### Рӯзи 67 — Такрор + sqlmap
- 📺 **Назария (1 соат):** sqlmap барои навомӯзон. Автоматизатсияи SQLi.
- 💻 **Амалия (3 соат):** Дар DVWA/ҳадафи таълимӣ `sqlmap -u "URL" --dbs`-ро иҷро кун. Вале аввал бифаҳм, ки он чӣ мекунад бо даст — вагарна бе асбоб оҷиз мемонӣ.
- ✍️ **Супориш (лоиҳаи хурд):** write-up «SQLi: бо даст vs sqlmap» дар GitHub.
- 🎯 **Худро санҷ:** чаро муҳим аст SQLi-ро бо даст донистан, на танҳо тавассути sqlmap?

## Ҳафтаи 10 — XSS, CSRF ва ҳамлаҳои муштарӣ

### Рӯзи 68 — XSS: скриптинги байнисайтӣ
- 📺 **Назария (1,5 соат):** XSS бо суханони содда. Reflected, Stored, DOM-based.
- 💻 **Амалия (2 соат):** PortSwigger — мавзӯи [«Cross-site scripting»](https://portswigger.net/web-security/cross-site-scripting), аввалин лабҳо. Классика: `<script>alert(1)</script>`.
- ✍️ **Супориш:** конспекти се навъи XSS бо мисолҳо.
- 🎯 **Худро санҷ:** reflected XSS аз stored чӣ фарқ дорад?

### Рӯзи 69 — XSS: эксплуатация ва дуздии сессияҳо
- 📺 **Назария (1,5 соат):** чӣ тавр тавассути XSS кукиро дуздидан, аз номи қурбонӣ амал кардан.
- 💻 **Амалия (2,5 соат):** PortSwigger — лабҳои stored ва DOM XSS. Payload нависон, ки кукиро медуздад (дар муҳити таълимӣ).
- ✍️ **Супориш:** write-up: эксплуатацияи stored XSS.
- 🎯 **Худро санҷ:** чаро stored XSS аз reflected хатарноктар аст?

### Рӯзи 70 — CSRF: сохтакории дархостҳо
- 📺 **Назария (1,5 соат):** CSRF бо суханони содда. Чӣ тавр браузери қурбониро маҷбур кардан, ки дархост фиристад.
- 💻 **Амалия (2 соат):** PortSwigger — мавзӯи [«CSRF»](https://portswigger.net/web-security/csrf), лабҳо. Нақши CSRF-токенҳоро бифаҳм.
- ✍️ **Супориш:** шарҳ деҳ, ки CSRF-токен чӣ тавр шаклро ҳифз мекунад.
- 🎯 **Худро санҷ:** чаро кукиҳои SameSite ба CSRF монеъ мешаванд?

### Рӯзи 71 — Аутентификатсия ва осебпазириҳои сессия
- 📺 **Назария (1,5 соат):** brute force, паролҳои суст, барқарорсозии нобехатари парол, фиксацияи сессия.
- 💻 **Амалия (2,5 соат):** PortSwigger — мавзӯи [«Authentication»](https://portswigger.net/web-security/authentication). Brute force тавассути Burp Intruder.
- ✍️ **Супориш:** brute force-и шакли таълимиро тавассути Intruder гузарон, нависон.
- 🎯 **Худро санҷ:** фиксацияи сессия (session fixation) чист?

### Рӯзи 72 — IDOR ва вайронкунии назорати дастрасӣ
- 📺 **Назария (1,5 соат):** IDOR бо суханони содда. `id=123`-ро ба `id=124` иваз мекунӣ ва додаҳои бегонаро мебинӣ.
- 💻 **Амалия (2,5 соат):** PortSwigger — мавзӯи [«Access control»](https://portswigger.net/web-security/access-control). IDOR — яке аз бештарин ёфтаҳо дар bug bounty.
- ✍️ **Супориш:** дар барномаи таълимӣ IDOR ёб, додаҳои бегонаро гир.
- 🎯 **Худро санҷ:** чаро IDOR ин қадар зуд-зуд дар барномаҳои воқеӣ вомехӯрад?

### Рӯзи 73 — Такрор + DVWA ҳамаи сатҳҳо
- 💻 **Амалия (3,5 соат):** DVWA-ро дар сатҳи Medium/High аз рӯи ҳамаи бахшҳое ки омӯхтӣ гузар (SQLi, XSS, CSRF).
- ✍️ **Супориш:** муқоиса кун, ки эксплуатация бо афзоиши сатҳи ҳифз чӣ тавр мушкил мешавад.
- 🎯 **Худро санҷ:** дар High кадом филтрҳо илова мешаванд ва чӣ тавр гузаштан?

### Рӯзи 74 — Codeby Games: масъалаҳои web
- 💻 **Амалия (3,5 соат):** [Codeby Games](https://codeby.games) — 4–5 масъалаи web-и сатҳҳои гуногунро ҳал кун.
- ✍️ **Супориш:** 2 write-up бо русӣ дар GitHub.
- 🎯 **Худро санҷ:** навъҳои осебпазириро зудтар аз як моҳ пеш мешиносӣ?

## Ҳафтаи 11 — Осебпазириҳои пешрафтаи web

### Рӯзи 75 — SSRF: сохтакории дархостҳои серверӣ
- 📺 **Назария (1,5 соат):** SSRF бо суханони содда. Маҷбур кардани сервер, ки ба захираҳои дохилӣ муроҷиат кунад.
- 💻 **Амалия (2,5 соат):** PortSwigger — мавзӯи [«SSRF»](https://portswigger.net/web-security/ssrf).
- ✍️ **Супориш:** шарҳ деҳ, ки SSRF дар инфрасохтори абрӣ чаро хатарнок аст (хидматҳои metadata).
- 🎯 **Худро санҷ:** ба ҳамлакунанда маҷбур кардани сервер ба дархостҳо барои чӣ лозим аст?

### Рӯзи 76 — File Upload ва Path Traversal
- 📺 **Назария (1,5 соат):** боркунии файлҳои зараровар (webshell), баромадан аз ҳудуди директория (`../../etc/passwd`).
- 💻 **Амалия (2,5 соат):** PortSwigger — мавзӯъҳои [«File upload»](https://portswigger.net/web-security/file-upload) ва [«Path traversal»](https://portswigger.net/web-security/file-path-traversal).
- ✍️ **Супориш:** webshell-ро ба барномаи таълимӣ бор кун, иҷрои фармонҳоро гир.
- 🎯 **Худро санҷ:** чӣ тавр .php бор кардан, агар сервер пасвандро санҷад?

### Рӯзи 77 — Command Injection
- 📺 **Назария (1,5 соат):** Command injection. Ворид кардани фармонҳои системавӣ тавассути вуруд.
- 💻 **Амалия (2,5 соат):** PortSwigger — мавзӯи [«OS command injection»](https://portswigger.net/web-security/os-command-injection). Ҷудокунандаҳо `;`, `|`, `&&`.
- ✍️ **Супориш:** RCE-ро тавассути command injection гир, нависон.
- 🎯 **Худро санҷ:** command injection аз SQLi аз рӯи механизм чӣ фарқ дорад?

### Рӯзи 78 — XXE ва десериализатсияи нобехатар
- 📺 **Назария (1,5 соат):** XML External Entity, десериализатсия (шарҳи умумӣ — ин душвортар аст).
- 💻 **Амалия (2,5 соат):** PortSwigger — мавзӯи [«XXE»](https://portswigger.net/web-security/xxe).
- ✍️ **Супориш:** `/etc/passwd`-ро тавассути XXE дар лаби таълимӣ хон.
- 🎯 **Худро санҷ:** сущияти берунӣ (external entity) дар XML чист?

### Рӯзи 79 — Амнияти API
- 📺 **Назария (1,5 соат):** OWASP API Top 10. REST, JSON, токенҳо, JWT.
- 💻 **Амалия (2,5 соат):** PortSwigger — мавзӯи [«API testing»](https://portswigger.net/web-security/api-testing). Сохтори JWT-ро дар [jwt.io](https://jwt.io/) таҳлил кун.
- ✍️ **Супориш:** JWT-токенро ба қисмҳо ҷудо кун, ҳар якро шарҳ деҳ.
- 🎯 **Худро санҷ:** чаро `alg: none` дар JWT — ин осебпазирӣ аст?

### Рӯзи 80 — Такрори ҳафта
- 💻 **Амалия (3,5 соат):** Лабҳои ноҳалли PortSwigger оид ба мавзӯъҳои пешрафтаро тамом кун.
- ✍️ **Супориш:** рӯйхати лабҳои гузаштаро нав кун, душворҳоро қайд кун.
- 🎯 **Худро санҷ:** чанд лаби PortSwigger аллакай пушти сар аст?

### Рӯзи 81 — TryHackMe: роҳи web
- 💻 **Амалия (3,5 соат):** THM — комнатаҳои [«OWASP Top 10»](https://tryhackme.com/room/owasptop10) ва [«Web Fundamentals»](https://tryhackme.com/module/web-fundamentals). Мустаҳкамкунӣ дар формати дигар.
- ✍️ **Супориш:** write-up-и мошини web.
- 🎯 **Худро санҷ:** OWASP-и THM бо он чи дар PortSwigger омӯхтӣ мувофиқ аст?
