# Моҳи 2 — Лабораторияи худӣ ва баланд бардоштани имтиёзҳо

**Мақсади моҳ:** сохтани лабораторияи ҷудошудаи хакерӣ, омӯхтани ҳамла ба мошинҳои осебпазир аз оғоз то охир, азхудкунии баланд бардоштани имтиёзҳо (privilege escalation) дар Linux ва Windows. Дар охири моҳ ту мошинҳои содаро худат мегузаронӣ.

**Захираҳои асосии моҳ:**
- 💻 [TryHackMe](https://tryhackme.com) — платформаи асосии амалия
- 🐉 [Kali Linux](https://www.kali.org/) — ОС-и кории ту (дар моҳи 1 насб шуд)
- 🎯 [VulnHub](https://www.vulnhub.com/) — мошинҳои осебпазири ройгон барои зеркашӣ
- 📖 [Codeby Games](https://codeby.games) — курси «Введение в CTF», модулҳои PrivEsc

> ⚠️ Ҳама чиз дар ин моҳ — **танҳо дар виртуалкаҳои худат ва платформаҳои таълимӣ**. Ҳеҷ системаи бегона.

## Ҳафтаи 5 — Лабораторияро месозем

### Рӯзи 31 — Меъмории лабораторияи хонагӣ
- 📺 **Назария (1,5 соат):** Чӣ тавр лабораторияи pentest сохтан. Шабакаи ҷудошуда, мошини ҳамлакунанда (Kali) + қурбониҳо.
- 💻 **Амалия (2 соат):** Дар VirtualBox шабакаи «Host-only» ё «Internal Network» танзим кун, то виртуалкаҳо якдигарро бинанд, вале аз интернет ҷудо бошанд. Санҷ, ки Kali шлюзро ping мекунад.
- ✍️ **Супориш:** нақшаи лабораторияи худро каш: кадом мошинҳо, кадом IP, кадом шабака.
- 🎯 **Худро санҷ:** чаро лабораторияро аз шабакаи хонагӣ ва интернет ҷудо мекунанд?

### Рӯзи 32 — Аввалин қурбонӣ: Metasploitable 2
- 📺 **Назария (1 соат):** [Metasploitable](https://sourceforge.net/projects/metasploitable/) чист — мошини қасдан сӯрохдор барои машқ.
- 💻 **Амалия (2,5 соат):** Metasploitable 2-ро дар VirtualBox зеркашӣ ва оғоз кун (дар ҳамон шабакаи ҷудошуда). Аз Kali `nmap -sV <IP-и қурбонӣ>`-ро иҷро кун — даҳҳо порти кушодаро мебинӣ.
- ✍️ **Супориш:** харитаи пурраи хидматҳои Metasploitable: порт → хидмат → версия.
- 🎯 **Худро санҷ:** кадом 3 хидмат аз ҳама куҳна/осебпазиртар менамоянд?

### Рӯзи 33 — Metasploit Framework: асосҳо
- 📺 **Назария (1,5 соат):** Metasploit барои навомӯзон. Мафҳумҳо: exploit, payload, module, `msfconsole`.
- 💻 **Амалия (2 соат):** Дар Kali `msfconsole`-ро оғоз кун. Фармонҳо: `search`, `use`, `show options`, `set`, `exploit`. vsftpd-и осебпазирро дар Metasploitable эксплуатация кун.
- ✍️ **Супориш:** қадам ба қадам нависон, ки чӣ тавр тавассути як эксплойт дастрасӣ гирифтӣ.
- 🎯 **Худро санҷ:** байни exploit ва payload чӣ фарқ аст?

### Рӯзи 34 — Reverse shell ва bind shell
- 📺 **Назария (1,5 соат):** Reverse shell бо суханони содда. Фарқи reverse vs bind.
- 💻 **Амалия (2 соат):** Дар Kali портро гӯш кун: `nc -lvnp 4444`. Аз қурбонӣ бозгашта пайваст шав. [Варақаи reverse shell](https://github.com/swisskyrepo/PayloadsAllTheThings/blob/master/Methodology%20and%20Resources/Reverse%20Shell%20Cheatsheet.md)-ро аз худ кун.
- ✍️ **Супориш:** аз Metasploitable ба Kali reverse shell бигир, скриншоти `whoami` соз.
- 🎯 **Худро санҷ:** чаро reverse shell бештар аз firewall мегузарад, назар ба bind shell?

### Рӯзи 35 — TryHackMe: роҳи Jr Penetration Tester (оғоз)
- 💻 **Амалия (3,5 соат):** Роҳи [Jr Penetration Tester](https://tryhackme.com/path/outline/jrpenetrationtester)-ро дар TryHackMe оғоз кун — модулҳои «Introduction to Pentesting» ва «Intro to Offensive Security».
- ✍️ **Супориш:** конспекти марҳилаҳои асосии pentest (recon → scan → exploit → post-exploit → report).
- 🎯 **Худро санҷ:** 5 марҳилаи pentest-ро аз рӯи тартиб ном бар.

### Рӯзи 36 — Codeby Games: модули Web Exploitation (оғоз)
- 💻 **Амалия (3,5 соат):** [Codeby Games](https://codeby.games), курси «Введение в CTF» — модул оид ба web (OWASP Top 10). 3–4 масъала ҳал кун.
- ✍️ **Супориш:** write-up-и як масъалаи web.
- 🎯 **Худро санҷ:** OWASP Top 10 бо ду калима чист?

### Рӯзи 37 — Такрори ҳафта + аввалин ҳамлаи пурра
- 💻 **Амалия (3 соат):** Давраи пурра дар Metasploitable **худат, бе дастур**: иктишоф → сканкунӣ → интихоби осебпазирӣ → эксплуатация → shell.
- ✍️ **Супориш (лоиҳаи хурд):** инро ҳамчун ҳисоботи pentest дар GitHub таҳия кун: ҳадаф, ёфтаҳо, қадамҳо, скриншотҳо, тавсияҳо.
- 🎯 **Худро санҷ:** бе ишора гузашта тавонистӣ? Агар ҳа — пеш рав.

## Ҳафтаи 6 — Баланд бардоштани имтиёзҳо дар Linux

### Рӯзи 38 — Privilege escalation чист
- 📺 **Назария (1,5 соат):** Linux Privilege Escalation барои навомӯзон. Аз корбари оддӣ то root.
- 💻 **Амалия (2 соат):** Комнатаи THM [«Linux PrivEsc»](https://tryhackme.com/room/linuxprivesc). Гузаштанро оғоз кун.
- ✍️ **Супориш:** рӯйхати 8 вектори баланд бардоштани имтиёзҳо дар Linux.
- 🎯 **Худро санҷ:** чаро гирифтани корбари оддӣ танҳо нисфи кор аст?

### Рӯзи 39 — Векторҳо: SUID, sudo, cron
- 📺 **Назария (1,5 соат):** таҳлили бинарҳои SUID, ҳуқуқи нодурусти `sudo`, вазифаҳои cron аз root.
- 💻 **Амалия (2 соат):** Дар мошини осебпазир: `sudo -l`, `find / -perm -4000 2>/dev/null`. Бо [GTFOBins](https://gtfobins.github.io/) муқоиса кун — пойгоҳи он ки чӣ тавр бинарҳои қонуниро суиистифода кардан.
- ✍️ **Супориш:** дар мошини THM як бинари SUID ёб ва тавассути GTFOBins то root боло шав.
- 🎯 **Худро санҷ:** GTFOBins чист ва чӣ тавр аз он истифода бурдан?

### Рӯзи 40 — Автоматизатсияи иктишоф: LinPEAS
- 📺 **Назария (1 соат):** шиносоӣ бо [PEASS-ng / LinPEAS](https://github.com/peass-ng/PEASS-ng) — скрипте ки худ роҳҳои баландшавиро меёбад.
- 💻 **Амалия (2,5 соат):** LinPEAS-ро ба мошини осебпазир бор кун, иҷро кун, натиҷаро таҳлил кун (чӣ бо сурх/зард нишон дода шудааст).
- ✍️ **Супориш:** LinPEAS-ро иҷро кун, 3 ёфтаи болоӣ ва маънои ҳар якро нависон.
- 🎯 **Худро санҷ:** чаро автоматикаро кӯр-кӯрона бовар кардан мумкин нест ва натиҷаро фаҳмидан лозим?

### Рӯзи 41 — Ядро, паролҳо, конфигҳо
- 📺 **Назария (1,5 соат):** осебпазириҳои ядро (kernel exploits), паролҳо дар конфигҳо/таърих, capabilities.
- 💻 **Амалия (2 соат):** Дар мошин ҷустуҷӯ кун: `cat ~/.bash_history`, `grep -r password /etc 2>/dev/null`, `getcap -r / 2>/dev/null`.
- ✍️ **Супориш:** ҳадди ақал як «сир» (парол/калид)-ро ки дар файл фаромӯш шудааст, дар мошини таълимӣ ёб.
- 🎯 **Худро санҷ:** барномасозон бештар дар куҷо тасодуфан паролҳоро мемонанд?

### Рӯзи 42 — TryHackMe: мустаҳкамкунии PrivEsc
- 💻 **Амалия (3,5 соат):** THM [«Linux PrivEsc»](https://tryhackme.com/room/linuxprivesc)-ро пурра гузар + комнатаи [«Common Linux Privesc»](https://tryhackme.com/room/commonlinuxprivesc).
- ✍️ **Супориш:** write-up: 3 усули гуногуни баландшавӣ, ки истифода бурдӣ.
- 🎯 **Худро санҷ:** аз хотир чек-листи санҷишҳоро барои privesc ном бурда метавонӣ?

### Рӯзи 43 — VulnHub: аввалин мошин «аз табиати ваҳшӣ»
- 📺 **Назария (30 дақ):** чӣ тавр мошинҳои [VulnHub](https://www.vulnhub.com/)-ро ба VirtualBox ворид кардан.
- 💻 **Амалия (3,5 соат):** Мошини сабукро зеркашӣ кун (масалан аз силсилаи «Basic Pentesting» ё «Kioptrix»). Пурра гузар: аз сканкунӣ то root.
- ✍️ **Супориш:** write-up-и худ дар GitHub.
- 🎯 **Худро санҷ:** аз nmap то root чанд қадам гузашт?

### Рӯзи 44 — Такрор + мошини дуюм
- 💻 **Амалия (3,5 соат):** Боз як мошини сабуки VulnHub/THM, бо ҳадди ақали ишора.
- ✍️ **Супориш (лоиҳаи хурд):** ҳарду таҳлилро зебо таҳия кун, ба репозиторийи `ctf-writeups` илова кун.
- 🎯 **Худро санҷ:** мошини дуюм осонтар шуд? Пешрафт меравад.

## Ҳафтаи 7 — Windows ва Active Directory (асосҳо)

### Рӯзи 45 — Асосҳои Windows барои мутахассиси амният
- 📺 **Назария (1,5 соат):** Windows барои pentester. Реестр, хидматҳо, равандҳо, SAM.
- 💻 **Амалия (2 соат):** Дар Windows-и худат: `whoami /priv`, `net user`, `systeminfo`, `tasklist`. PowerShell: `Get-Process`, `Get-Service`.
- ✍️ **Супориш:** 10 фармони иктишофи Windows ва он чӣ ҳар як нишон медиҳад.
- 🎯 **Худро санҷ:** Windows хешҳои паролҳои маҳаллиро дар куҷо нигоҳ медорад?

### Рӯзи 46 — PowerShell барои амният
- 📺 **Назария (1,5 соат):** PowerShell барои навомӯзон. Командлетҳо, пайплайн, объектҳо.
- 💻 **Амалия (2 соат):** Скрипти PowerShell нависон, ки маълумоти системаро ҷамъ мекунад (аналоги sysinfo-и bash, вале барои Windows).
- ✍️ **Супориш:** скриптро дар GitHub бор кун.
- 🎯 **Худро санҷ:** пайплайни PowerShell аз bash чӣ фарқ дорад (объектҳо vs матн)?

### Рӯзи 47 — Active Directory чист
- 📺 **Назария (2 соат):** Active Directory бо суханони содда. Домен, контроллери домен, корбарон, гурӯҳҳо, GPO. **Ин муҳим аст** — 90%-и ҳамлаҳои корпоративӣ дар атрофи AD давр мезананд.
- 💻 **Амалия (1,5 соат):** Комнатаи THM [«Active Directory Basics»](https://tryhackme.com/room/winadbasics).
- ✍️ **Супориш:** нақшаи домени AD-ро каш: DC, корбарон, гурӯҳҳо, компютерҳо.
- 🎯 **Худро санҷ:** контроллери домен чист ва чаро ҳадафи асосии ҳамлакунанда аст?

### Рӯзи 48 — Windows Privilege Escalation
- 📺 **Назария (1,5 соат):** Windows PrivEsc. Хидматҳо, токенҳо, реестр, unquoted service path.
- 💻 **Амалия (2 соат):** THM [«Windows PrivEsc»](https://tryhackme.com/room/windows10privesc). Асбоб: [WinPEAS](https://github.com/peass-ng/PEASS-ng).
- ✍️ **Супориш:** дар мошини таълимӣ то Administrator боло шав, векторро нависон.
- 🎯 **Худро санҷ:** 3 вектори privesc дар Windows ном бар.

### Рӯзи 49 — Маълумоти вуруд ва хешҳои Windows
- 📺 **Назария (1,5 соат):** NTLM-хешҳо, [Mimikatz](https://github.com/gentilkiwi/mimikatz) чист, pass-the-hash (шарҳи умумӣ).
- 💻 **Амалия (2 соат):** Комнатаи THM оид ба dump-и маълумоти вуруд. Бифаҳм, ки хешҳо чӣ тавр гирифта ва аз нав истифода мешаванд.
- ✍️ **Супориш:** бо суханони худ ҳамлаи pass-the-hash-ро шарҳ деҳ.
- 🎯 **Худро санҷ:** чаро NTLM-хеши дуздидашуда ҳатто бе донистани худи парол хатарнок аст?

### Рӯзи 50 — TryHackMe: мустаҳкамкунии Windows
- 💻 **Амалия (3,5 соат):** 1–2 мошини сабуки Windows-ро дар THM бо давраи пурра гузар.
- ✍️ **Супориш:** write-up-и мошини Windows дар GitHub.
- 🎯 **Худро санҷ:** иктишофи Windows аллакай худкор шуд?

### Рӯзи 51 — Такрори ҳафта
- 💻 **Амалия (3,5 соат):** Комнатаи захиравии Windows/AD-ро гузар, нофаҳмиҳои ҳафтаро гир.
- ✍️ **Супориш:** дафтарчаро нав кун, репозиторийро ба тартиб ор.
- 🎯 **Худро санҷ:** privesc дар куҷо осонтар меояд — дар Linux ё Windows? Чаро?
