# 💼 Баъд аз курс — касбҳо, музди меҳнат, минбаъд чӣ

Баъд аз 270 рӯз ба куҷо рафтан. Барои ҳар касб: чӣ кор мекунӣ, ориентири музд, минбаъд чӣ омӯхтан, кадом сертификатҳо.

> ⚠️ **Дар бораи музд ростқавлона.** Рақамҳо — ориентири дағал барои соли 2026, онҳо аз минтақа, ширкат ва бахт сахт вобастаанд. Барои Тоҷикистон/Осиёи Миёна музди маҳаллии IT хеле пасттар аст; **роҳи воқеӣ ба даромади баланд — кори дурдаст (remote) барои ширкатҳои русӣ ва байналмилалӣ.** Ин маслиҳати молиявӣ нест, балки шарҳи бозор. Диапазонҳо — «ба ҳисоби миёна дар бозор», на кафолат.

---

## 🔵 Junior SOC Analyst (ҳифз) — соддатарин вуруд

**Чӣ кор мекунӣ:** ҳодисаҳои амниятиро мониторинг мекунӣ, алертҳоро таҳлил мекунӣ, эскалатсия мекунӣ, дар SIEM кор мекунӣ.

**Чаро вуруд осонтар:** ҷойҳои корӣ аз ҳама бештар, навомӯзон ва стажёронро бо хушӣ мегиранд, аксар вақт таълими дохилӣ ҳаст.

**Музд (ориентир, РФ/дурдаст):** Junior ~60–120к ₽/моҳ → Middle ~150–250к ₽.

**Минбаъд чӣ омӯхтан:** SIEM-и амиқтар (вендори ширкат), threat hunting, detection engineering (моҳи 8), автоматизатсия (SOAR).

**Сертификатҳо:** CompTIA Security+, BTL1, баъд — GCIA/GCIH.

**Асос дар курс:** моҳҳои 5, 8.

---

## 🔴 Junior Pentester (ҳамла)

**Чӣ кор мекунӣ:** осебпазириҳоро дар системаҳо/шабакаҳо/барномаҳо аз рӯи фармоиш меҷӯӣ, ҳисоботҳо бо тавсияҳо менависӣ.

**Воқеият:** ҷолибтар садо медиҳад, вале junior-ро камтар мегиранд — сатҳи баландтар ва аксар вақт портфолио/CTF-рейтинг лозим. Қадами дуюми хуб баъд аз SOC.

**Музд (ориентир):** Junior ~80–150к ₽ → Middle ~180–300к ₽.

**Минбаъд чӣ омӯхтан:** AD-и пешрафта, гузаштан аз ҳифзҳо (evasion), C2-фреймворкҳо, red team — нигаред [advanced-course.md](advanced-course.md).

**Сертификатҳо:** eJPT (оғоз) → OSCP (стандарти тиллоӣ, ҳадаф барои 1–2 сол) → OSEP/CRTP.

**Асос дар курс:** моҳҳои 2, 3, 4.

---

## 🟢 AppSec Engineer (амнияти барномаҳо) — топ барои ту бо Python

**Чӣ кор мекунӣ:** осебпазириҳоро дар код ва барномаҳо меҷӯӣ, амниятро ба таҳия дохил мекунӣ, ревюи код, threat modeling.

**Чаро ба ту мувофиқ аст:** Python-и ту + web (моҳи 3) + DevSecOps (моҳи 8) = роҳи мустақим. Баланд қадр карда мешавад.

**Музд (ориентир):** Junior ~100–170к ₽ → Middle/Senior ~200–400к+ ₽.

**Минбаъд чӣ омӯхтан:** SAST/DAST-и амиқ, secure code review, забонҳо (Java/Go/JS), API security, threat modeling.

**Сертификатҳо:** як «асосӣ» нест; портфолио, bug bounty, баъд CSSLP қадр мешаванд.

**Асос дар курс:** моҳҳои 3, 8.

---

## ☁️ Cloud Security Engineer — топ-камёбии бозор

**Чӣ кор мекунӣ:** инфрасохтори абриро (AWS/Azure/GCP) ҳифз мекунӣ, IAM, аудити конфигуратсияҳо, амнияти cloud-native.

**Воқеият:** талаботи бузург, мутахассис кам — музд аз миёна баландтар. Одатан баъд аз таҷрибаи асосӣ меоянд.

**Музд (ориентир):** Junior ~120–200к ₽ → Middle/Senior ~250–450к+ ₽.

**Минбаъд чӣ омӯхтан:** як провайдери амиқ, Kubernetes security, IaC (Terraform) security, cloud detection.

**Сертификатҳо:** AWS Security Specialty, AZ-500, CCSK/CKS (Kubernetes).

**Асос дар курс:** моҳи 7.

---

## 🔧 DevSecOps Engineer

**Чӣ кор мекунӣ:** амниятро ба CI/CD дохил мекунӣ, сканкуниро автоматизатсия мекунӣ, secrets-ро идора мекунӣ, инфрасохтор ҳамчун код.

**Чаро серталаб:** ширкатҳо DevSecOps-ро оммавӣ ҷорӣ мекунанд, одам намерасад.

**Музд (ориентир):** Junior ~120–200к ₽ → Middle/Senior ~250–450к+ ₽.

**Минбаъд чӣ омӯхтан:** Kubernetes, Terraform, абр, supply chain security, платформасозӣ.

**Сертификатҳо:** CKS, сертификатҳои security-и абрӣ.

**Асос дар курс:** моҳҳои 7, 8.

---

## 🎯 Detection Engineer

**Чӣ кор мекунӣ:** қоидаҳои ошкори ҳамларо (Sigma/YARA) менависӣ ва танзим мекунӣ, фарогирӣ аз рӯи MITRE ATT&CK-ро рушд медиҳӣ, detection-as-code.

**Воқеият:** эволютсия аз SOC-таҳлилгар, роҳи арзишманд ва «муҳандисӣ».

**Музд (ориентир):** ~150–300к ₽ ва баландтар.

**Минбаъд чӣ омӯхтан:** ATT&CK-и амиқ, threat intelligence, adversary emulation, SIEM/EDR-и мушаххас.

**Асос дар курс:** моҳи 8 (ҳафтаҳои 30–31).

---

## 🤖 AI Security Engineer — касби оянда (аллакай ҳозира)

**Чӣ кор мекунӣ:** системаҳои AI/LLM-ро санҷ ва ҳифз мекунӣ: prompt injection, амнияти агентҳо/MCP, guardrails, AI red teaming.

**Воқеият:** самт нав, мутахассис қариб нест — кӣ барвақт дарояд, дар нӯг хоҳад буд. Ҳоло бештар ҳамчун тахассус дар болои AppSec/pentest, вале талабот босуръат меафзояд.

**Музд (ориентир):** баланд аз сабаби камёбӣ; аз ширкат сахт вобаста, аксар вақт дар сатҳи senior AppSec ва баландтар.

**Минбаъд чӣ омӯхтан:** асосҳои ML, амнияти системаҳои агентӣ, тадқиқоти актуалӣ (OWASP LLM, MITRE ATLAS), red teaming-и LLM.

**Асос дар курс:** моҳи 9 — ту аллакай пеш аз аксари junior-ҳо хоҳӣ буд.

## 🧭 Чӣ тавр интихоб кардан

| Мехоҳӣ… | Ба ту ин ҷо | Вуруд |
|---|---|---|
| Зудтар кор ёфтан | SOC Analyst | осон |
| Python истифода бурдан | AppSec / AI Security | миёна |
| Системаҳоро шикастан | Pentester | душвортар |
| Маҳорати камёби серталаб | Cloud / AI Security | миёна |
| Муҳандисӣ + автоматизатсия | DevSecOps / Detection | миёна |

Маслиҳат: барои **аввалин** кор соддатарин вурудро гир (SOC/AppSec), тахассусро дар раванд амиқ кун. Гузаштан дар дохили касб осон аст.

## 📈 Нақшаи умумии рушд

```
Junior (0–1.5 сол) ──► Middle (1.5–4 сол) ──► Senior (4+ сол)
   ↑ ту ин ҷо          ↑ тахассус              ↑ таҷриба + OSCP/сертификатҳои эксперт
```

1. Junior шав (истодагарӣ аз резюмеи беайб муҳимтар).
2. Сертификати аввал бо ёрии корфармо.
3. Дар як соҳа амиқ шав.
4. Пас аз 1.5–2 сол — сертификати вазнин (OSCP / профилӣ) ва сатҳи мутахассиси боэътимод.
5. Ба бештар омодаӣ? → [advanced-course.md](advanced-course.md).

**Бозори ИБ гурусна аст. Мутахассис намерасад. Бо асос, портфолио ва истодагарӣ ту ҷой меёбӣ. Баъди курс наист — дар он ҷо ҷолибтарин оғоз мешавад.**
