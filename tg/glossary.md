# Луғати истилоҳот — англисӣ ↔ тоҷикӣ

Мушкили асосии ту дар оғоз — истилоҳоти англисӣ. Дар ин ҷо ҳамаи он чи дар курс вомехӯрад ҷамъ шудааст. Файлро кушода нигоҳ дор ва вақте калимаи ношинос дидӣ, ин ҷо нигоҳ кун. Истилоҳот аз рӯи мавзӯъҳо гурӯҳбандӣ шудаанд.

> Чӣ тавр омӯхтан: рӯйхатро аз ёд накун. Дар дарс истилоҳ дидӣ → ин ҷо ёфтӣ → баъд аз 3–4 такрор дар контекст худаш мемонад.

## 🌐 Шабакаҳо (моҳи 1)

| Англисӣ | Тоҷикӣ / Шарҳ |
|---|---|
| Packet | Пакет — порчаи додаҳо, ки дар шабака сафар мекунад |
| Frame | Фрейм / кадр — пакет дар сатҳи кан/L2 |
| Payload | Бори муфид — худи додаҳо дар дохили пакет |
| Header | Сарлавҳа — маълумоти хидматӣ дар аввали пакет |
| Protocol | Протокол — қоидаҳои муошират (HTTP, TCP...) |
| Handshake | Дастфишорӣ — барқарорсозии пайваст (SYN→SYN-ACK→ACK) |
| Subnet | Зершабака — қисми шабака (масалан /24) |
| Gateway | Шлюз — роутер, дари ба шабакаи дигар |
| Router | Маршрутизатор — пакетҳоро байни шабакаҳо мефиристад (L3) |
| Switch | Свитч — дар дохили шабака мефиристад (L2) |
| Port | Порт — «дари» хидмат (80 = HTTP) |
| Resolve | Ҳал кардани ном — табдили ном ба IP тавассути DNS |

## 🔤 40 калимаи англисии техникӣ

Агар ин калимаҳоро донӣ — 80%-и маводҳои англисиро мехонӣ. Аввал инҳоро аз ёд кун:

`enable / disable` (фаъол/ғайрифаъол), `allow / deny` (иҷозат/манъ), `request / response` (дархост/ҷавоб), `source / destination` (манбаъ/таъинот), `input / output` (вуруд/барориш), `default` (пешфарз), `available` (дастрас), `required` (лозим), `failed / success` (нокомӣ/муваффақият), `attempt` (кӯшиш), `retrieve` (гирифтан), `credentials` (маълумоти вуруд), `bypass` (гузаштан/дур задан), `mitigate` (кам кардани хатар), `patch` (навкунӣ/ямоқ), `disclose` (ошкор кардан), `remote / local` (дурдаст/маҳаллӣ), `arbitrary` (ихтиёрӣ), `crafted` (махсус сохташуда), `malicious` (зараровар), `legitimate` (қонунӣ/воқеӣ), `spoof` (сохта кардан), `harden` (мустаҳкам кардан).
