# 🎯 Саволҳо барои мусоҳиба — бонк бо ҷавобҳо

Саволҳое ки воқеан ба junior-ҳо дар ИБ медиҳанд, бо ҷавобҳои мухтасар. Аз ёд накун — **бифаҳм**. Дар мусоҳиба фаҳмишро қадр мекунанд, на матни азёдкардашударо.

**Чӣ тавр тайёрӣ дидан:** ҷавобро пӯшон, бо суханони худ баланд ҷавоб додан кӯшиш кун, сипас муқоиса кун. Натавонистӣ — ба моҳи мувофиқи курс баргард.

## Асос

**1. Триадаи CIA чист?**
Confidentiality (махфият), Integrity (тамомият), Availability (дастрасӣ) — се хосияте ки ИБ ҳифз мекунад. Рамзгузорӣ C-ро ҳифз мекунад, хешҳо/имзоҳо — I, захира ва ҳифз аз DoS — A.

**2. Осебпазирӣ аз эксплойт ва таҳдид аз хатар чӣ фарқ доранд?**
Осебпазирӣ — ҷойи суст. Эксплойт — усули истифодаи он. Таҳдид — рӯйдоди эҳтимолӣ. Хатар — эҳтимолияти таҳдид × зарар.

**3. Аутентификатсия vs авторизатсия?**
Аутентификатсия — «ту кистӣ» (санҷиши шахсият). Авторизатсия — «ба ту чӣ мумкин» (санҷиши ҳуқуқ). Аввал якум, баъд дуюм.

**4. Принсипи камтарин имтиёз чист?**
Ба субъект маҳз ҳамон ҳуқуқеро додан, ки барои вазифа лозим аст, на бештар. Зарарро ҳангоми компрометатсия маҳдуд мекунад.

**5. Defense in depth чист?**
Ҳифзи эшелонӣ: якчанд қабати мустақил (периметр, шабака, хост, барнома, додаҳо), то шикастани як қабат дастрасии пурра надиҳад.

**6. Рамзгузории симметрӣ vs асимметрӣ?**
Симметрӣ — як калид барои рамзгузорӣ ва рамзкушоӣ (AES), зуд. Асимметрӣ — ҷуфти калидҳо: кушода рамз мекунад, пӯшида рамзкушоӣ мекунад (RSA), сусттар. Дар амал омехта мекунанд: бо асимметрия калиди симметриро интиқол медиҳанд.

**7. Хеш чист ва аз рамзгузорӣ чӣ фарқ дорад?**
Хеш — табдили яктарафаи баргаштнопазир бо дарозии собит (SHA-256). Рамзгузорӣ ҳангоми мавҷудияти калид баргаштпазир аст. Хешро «рамзкушоӣ» кардан мумкин нест.

**8. Намак (salt) барои чӣ лозим аст?**
Иловаи тасодуфӣ ба парол пеш аз хешкунӣ. Аз ҷадвалҳои рангинкамон ҳифз мекунад ва паролҳои якхеларо аз рӯи хеш гуногун мекунад.

**9. 0-day чист?**
Осебпазирие ки барои он ҳанӯз ямоқ нест (вендор «0 рӯз» барои ислоҳ дорад).

**10. MITRE ATT&CK чист?**
Пойгоҳи донишҳои тактика ва техникаҳои ҳамлакунандагон, ки ба мушоҳидаҳои воқеӣ асос ёфтааст. Барои тавсифи ҳамлаҳо, фарогирӣ бо детектҳо ва threat hunting истифода мешавад.

## Шабакаҳо

**11. Дар бораи модели OSI нақл кун.**
7 сатҳ: ҷисмонӣ, каналӣ (MAC), шабакавӣ (IP), транспортӣ (TCP/UDP), сеансӣ, намоиш, амалӣ (HTTP). Додаҳо ҳангоми интиқол бо қабатҳо «печонида» мешаванд.

**12. IP ва MAC дар кадом сатҳҳо кор мекунанд?**
IP — сатҳи 3 (шабакавӣ, байни шабакаҳо). MAC — сатҳи 2 (каналӣ, дар дохили як шабака).

**13. TCP vs UDP?**
TCP — бо барқарорсозии пайваст, расонидан ва тартибро кафолат медиҳад (веб, почта). UDP — бе пайваст, зудтар, бе кафолат (DNS, стриминг, бозиҳо).

**14. TCP handshake-ро тавсиф кун.**
SYN → SYN-ACK → ACK. Муштарӣ пайвастро дархост мекунад, сервер тасдиқ мекунад, муштарӣ тасдиқи тасдиқро мефиристад.

**15. Ҳангоми ворид кардани URL дар браузер чӣ мешавад?**
DNS-резолви домен ба IP → пайвасти TCP (ва TLS-handshake барои HTTPS) → дархости HTTP → сервер ҷавоб медиҳад → браузер рендер мекунад.

**16. Портҳои 22, 80, 443, 53, 3389, 445?**
SSH, HTTP, HTTPS, DNS, RDP, SMB.

**17. Провайдер ҳангоми HTTPS чиро мебинад?**
Домен (тавассути SNI/DNS), IP, ҳаҷм ва вақти трафик. Мазмуни дархостҳо/ҷавобҳо ва роҳи URL-ро намебинад.

**18. NAT чист?**
Тарҷумаи адресҳо: адресҳои зиёди хусусӣ дар паси як оммавӣ. IPv4-ро сарфа мекунад ва шабакаи дохилиро пинҳон мекунад.

**19. VPN чист ва чиро ҳифз мекунад?**
Туннели рамзшуда. Трафикро аз шунидан дар шабакаи нобоварбахш ҳифз мекунад ва IP-и намоёнро иваз мекунад. Худ ба худ беном намекунад.

## Linux / Windows

**20. `-rwxr-x---` чиро ифода мекунад?**
Соҳиб: хондан/навиштан/иҷро; гурӯҳ: хондан/иҷро; боқимонда: ҳеҷ чиз.

**21. Бити SUID чист ва чаро хатарнок аст?**
Файл бо ҳуқуқи соҳиб иҷро мешавад, на бо ҳуқуқи оғозкунанда. Агар ин бинари root бо осебпазирӣ бошад — роҳ ба баланд бардоштани имтиёзҳо.

**22. Хешҳои паролҳо дар Linux ва Windows дар куҷо нигоҳ дошта мешаванд?**
Linux — `/etc/shadow` (дастрасӣ танҳо root). Windows — пойгоҳи SAM ва LSASS дар хотира.

**23. Чӣ тавр ҳамаи файлҳои SUID-ро ёфтан?**
`find / -perm -4000 2>/dev/null`.

**24. GTFOBins / LOLBAS чист?**
Пойгоҳҳои бинарҳои қонунӣ, ки метавон онҳоро суиистифода кард (privesc, гузаштан, иҷрои фармонҳо). GTFOBins — Linux, LOLBAS — Windows.

**25. Active Directory ва контроллери домен чист?**
AD — хидмати каталогҳои Microsoft (корбарон, компютерҳо, гурӯҳҳо, сиёсатҳо). DC — сервере ки доменро нигоҳ медорад ва хизмат мерасонад; ҳадафи асосии ҳамлакунанда.

**26. Pass-the-hash чист?**
Аутентификатсия бо истифодаи хеши NTLM бе донистани худи парол. Аз сабаби хусусиятҳои NTLM кор мекунад.

**27. Kerberoasting чист?**
Дархости билетҳои хидматии Kerberos (SPN) ва брути офлайни хешҳои онҳо барои гирифтани паролҳои аккаунтҳои хидматӣ.

## Амнияти веб

**28. OWASP Top 10-ро номбар кун (ҳадди ақал нисфашро).**
Broken Access Control, Cryptographic Failures, Injection, Insecure Design, Security Misconfiguration, Vulnerable Components, Auth Failures, Data Integrity Failures, Logging Failures, SSRF.

**29. SQL-инъексия чист ва чӣ тавр ҳифз шудан?**
Ворид кардани SQL тавассути вуруди корбар. Ҳифз: дархостҳои параметрдор (prepared statements), ORM, валидатсия, камтарин имтиёзи БД.

**30. Навъҳои XSS?**
Reflected (аз дархост ба ҷавоб), Stored (дар сервер нигоҳ дошта мешавад), DOM-based (дар JS дар муштарӣ). Ҳифз: кодиронии баромад, CSP, HttpOnly-кукиҳо.

**31. CSRF чист ва чӣ тавр ҳифз шудан?**
Маҷбур кардани браузери қурбонӣ, ки дархостро аз номи ӯ фиристад. Ҳифз: CSRF-токенҳо, SameSite-кукиҳо, санҷиши Origin/Referer.

**32. IDOR чист?**
Ишораи мустақими нобехатар ба объект: `id=1`-ро ба `id=2` иваз мекунӣ ва додаҳои бегонаро мегирӣ. Сабаб — набудани санҷиши ҳуқуқ ба объект.

**33. Reflected vs Stored XSS — кадомаш хатарноктар?**
Stored: payload нигоҳ дошта мешавад ва ба ҳамаи касоне ки саҳифаро кушоданд мезанад, бе амали онҳо. Reflected талаб мекунад, ки қурбонӣ бо пайванди тайёршуда гузарад.

**34. SSRF чист ва дар абр чаро хатарнок?**
Маҷбур кардани сервер, ки дархостро ба ҷои ҳамлакунанда кунад. Дар абр — дастрасӣ ба хидмати metadata (169.254.169.254) ва дуздии креденшелҳои муваққатӣ.

**35. Command injection чист?**
Ворид кардани фармонҳои системавӣ тавассути вуруде ки ба даъвати ОС меафтад. Ҷудокунандаҳо `;`, `|`, `&&`. Ҳифз: shell-ро даъват накардан, allow-list, экранкунӣ.

**36. SameSite дар куки чист?**
Атрибуте ки фиристодани кукиро дар дархостҳои байнисайтӣ маҳдуд мекунад (Strict/Lax/None). Ба зидди CSRF кӯмак мекунад.

**37. HttpOnly ва Secure дар куки?**
HttpOnly — кукиро аз JS хондан мумкин нест (ҳифз аз дуздӣ тавассути XSS). Secure — танҳо тавассути HTTPS фиристода мешавад.

**38. JWT чист ва ҷойҳои сусташ куҷост?**
JSON Web Token — токени имзошуда аз header.payload.signature. Ҷойҳои суст: `alg: none`, сирри суст, набудани санҷиши имзо/мӯҳлат, додаҳои ҳассос дар payload-и рамзнашуда.

**39. CORS чист?**
Механизме ки дархостҳои байнидомениро аз браузер иҷозат/манъ мекунад. Мисконфиг (`*` бо credentials) метавонад ба ихроҷи додаҳо орад.

**40. Burp Suite чӣ тавр кор мекунад?**
Прокси байни браузер ва сервер: дархостҳоро мегирад, тағйир медиҳад ва такрор мефиристад. Repeater — такрори дастӣ, Intruder — автоматизатсия/брут, Scanner (Pro) — ҷустуҷӯи худкор.

## Криптография

**41. TLS handshake бо суханони содда?**
Дар бораи шифрҳо мувофиқа кардан, сертификати серверро санҷидан (боварӣ тавассути CA), калидҳо мубодила кардан ва ба канали рамзшуда гузаштан.

**42. Сертификат ва маркази сертификатсия (CA) чист?**
Сертификат доменро бо калиди кушода мепайвандад, аз ҷониби CA имзо шудааст. Браузер ба CA бовар мекунад → ба сертификат бовар мекунад.

**43. MITM чист?**
Ҳамлакунанда байни тарафҳо меистад, трафикро мегирад/тағйир медиҳад. HTTPS бо сертификати эътиборнок инро пешгирӣ мекунад.

**44. Чаро MD5/SHA1-ро барои паролҳо истифода бурдан мумкин нест?**
Зуданд ва коллизия доранд. Барои паролҳо функсияҳои суст ва мутобиқшаванда лозиманд: bcrypt, scrypt, Argon2.

**45. Хешкунӣ vs рамзгузорӣ vs кодиронӣ?**
Хеш — баргаштнопазир. Рамзгузорӣ — бо калид баргаштпазир. Кодиронӣ (Base64) — бе калид баргаштпазир, ин ҲИФЗ НЕСТ.

## Треки SOC / Blue Team

**46. SOC-таҳлилгари L1 чӣ мекунад?**
Алертҳоро мониторинг мекунад, триажи аввалия мегузаронад, false positive-ро ҷудо мекунад, ҳодисаҳои воқеиро ба L2/L3 эскалатсия мекунад.

**47. SIEM чист?**
Системаи ҷамъоварӣ, корреляция ва таҳлили логҳо аз манбаъҳои гуногун. Мисолҳо: Splunk, Elastic, Wazuh, QRadar.

**48. False positive vs false negative?**
FP — ба нотаҳдид кор кард (садо). FN — ҳамлаи воқеиро гузаронд (хатарноктар). Танзими детектҳо байни онҳо мувозинат мекунад.

**49. Таҳдиди воқеиро аз сигнали бардурӯғ чӣ тавр фарқ кардан?**
Контекст: манбаъ, обрӯи IP/хеш, рафтор (baseline), корреляция бо рӯйдодҳои дигар, маълумият будани раванд/аккаунт.

**50. Windows Event ID 4624 ва 4625?**
4624 — вуруди муваффақ, 4625 — нокоом. Бисёр 4625-и пай дар пай = брутфорси эҳтимолӣ.

**51. IOC чист, мисол биёр?**
Indicator of Compromise — аломати шикаст: хеши файл, IP/домени C2, номи мьютекс, калиди реестр, раванди ғайриодӣ.

**52. IOC vs TTP?**
IOC — артефактҳои мушаххас (ҳамлакунанда осон иваз мекунад). TTP — тактика/техника/процедураҳо, «дастхат» (иваз кардан гарон, детект устувортар). Пирамидаи дарди Bianco.

**53. Threat hunting чист ва аз вокуниш ба алерт чӣ фарқ дорад?**
Ҷустуҷӯи проактивии таҳдидҳои пинҳонӣ аз рӯи фарзияҳо (бе алерти корда). Вокуниш — реактивӣ, аз рӯи алерт.

**54. EDR чист ва аз антивирус чӣ беҳтар?**
Endpoint Detection & Response: ба рафтори равандҳо менигарад, на танҳо ба имзоҳо; телеметрия, ҷустуҷӯ ва вокуниш медиҳад. Fileless ва таҳдидҳои навро мегирад.

**55. Раванди Incident Response-ро тавсиф кун.**
NIST: омодагӣ → ошкор ва таҳлил → маҳдудкунӣ → бартарафкунӣ → барқарорсозӣ → дарсҳо.

**56. Sysmon чист ва барои чӣ лозим?**
Асбоби логгонии васеъкардашудаи Windows (сохтани равандҳо, пайвастҳои шабакавӣ, тағйироти файлҳо/реестр). Асоси детектҳо.

**57. Sigma чист?**
Формати универсалии қоидаҳои детект, ки ба SIEM-ҳои гуногун табдил меёбад. «YAML барои детектҳо».

**58. Марҳилаҳои Cyber Kill Chain?**
Reconnaissance, Weaponization, Delivery, Exploitation, Installation, C2, Actions on Objectives.

**59. Номаи фишингиро чӣ тавр тафтиш мекардӣ?**
Сарлавҳаҳо (SPF/DKIM/DMARC, фиристандаи воқеӣ), пайвандҳо/замимаҳо дар песочница, IOC, кӣ боз гирифт, чиро кушоданд, ҳангоми зарурат ҷудокунӣ.

## Треки Pentest / Red Team

**60. Марҳилаҳои pentest?**
Иктишоф → сканкунӣ → таҳлили осебпазириҳо → эксплуатация → пост-эксплуатация → ҳисобот.

**61. Black box vs grey box vs white box?**
Бе маълумот / маълумоти қисман (аккаунт, схема) / дастрасии пурра ба код ва меъморӣ.

**62. Reverse shell vs bind shell?**
Reverse — қурбонӣ ба ҳамлакунанда пайваст мешавад (аз firewall-и воридотӣ мегузарад). Bind — ҳамлакунанда ба порти гӯшкунандаи қурбонӣ пайваст мешавад.

**63. Пас аз гирифтани foothold чӣ мекунӣ?**
Иктишоф дар хост, баланд бардоштани имтиёзҳо, ҷамъоварии креденшелҳо, баҳодиҳии ҳаракати паҳлӯӣ, мустаҳкамшавӣ (дар доираи scope).

**64. Векторҳои баланд бардоштани имтиёзҳо дар Linux?**
SUID/SGID, мисконфиги sudo, cron аз root, ҳуқуқи навиштан дар PATH, capabilities, kernel exploits, креденшелҳо дар файлҳо.

**65. BloodHound чист?**
Графи муносибатҳоро дар AD месозад ва роҳҳои кӯтоҳтаринро то Domain Admin меёбад. Додаҳои SharpHound-ро истифода мебарад.

**66. Ҳаракати паҳлӯӣ чист ва мисолҳо?**
Гузариш байни хостҳо дар шабака: pass-the-hash, pass-the-ticket, PsExec/WMI (Impacket), RDP, SMB.

**67. Вектори CVSS чӣ тавр хонда мешавад?**
Метрикаҳо: Attack Vector, Complexity, Privileges Required, User Interaction, Scope, таъсири C/I/A → баҳои асосӣ 0–10.

**68. Дар pentest чӣ муҳимтар — эксплойт ё ҳисобот?**
Ҳисобот. Ба фармоишгар ёфтаҳои фаҳмо, хатар ва тавсияҳо лозиманд, на танҳо «ман root гирифтам».

**69. Nmap: `-sS` аз `-sT` чӣ фарқ дорад?**
`-sS` — SYN-скан (нимкушода, оромтар, имтиёз лозим). `-sT` — TCP-connect-и пурра (садоноктар, бе имтиёз).

**70. Pivoting чист?**
Истифодаи хости компрометатсияшуда ҳамчун «трамплин» барои дастрасӣ ба шабакаи дохилии бевосита дастнорас (проброси портҳо, туннелҳо).

## Треки AppSec

**71. SAST, DAST, IAST, SCA чист?**
SAST — таҳлили коди сарчашма бе оғоз. DAST — санҷиши барномаи коркунда аз берун. IAST — аз дарун ҳангоми иҷро. SCA — таҳлили вобастагиҳои беруна.

**72. Ҳамлаи supply chain чист?**
Компрометатсия тавассути вобастагиҳо/асбобҳои васл/навсозиҳо (мисолҳо: xz, event-stream, SolarWinds). Ҳифз: SCA, SBOM, имзои артефактҳо, сабти версияҳо.

**73. SBOM чист?**
Software Bill of Materials — рӯйхати ҳамаи компонентҳои нармафзор. Имкон медиҳад фавран донед, оё маҳсулот ба CVE-и нав (мисли Log4Shell) дучор аст.

**74. Паролҳои корбаронро чӣ тавр бехатар нигоҳ доштан?**
Argon2/bcrypt/scrypt бо намак, ҳеҷ гоҳ дар шакли кушода ва на MD5/SHA. Плюс ҳифз аз брутфорс (rate limit, lockout).

**75. Threat modeling чист?**
Таҳлили низомманди система аз нигоҳи таҳдидҳо (масалан STRIDE: Spoofing, Tampering, Repudiation, Info disclosure, DoS, Elevation). Дар марҳилаи тарҳрезӣ анҷом дода мешавад.

**76. Insecure deserialization чист?**
Десериализатсияи нобехатари додаҳои нобоварбахш → иҷрои код/мантиқ. Мисол: `pickle` дар Python, объектҳои Java.

**77. API-ро чӣ тавр ҳифз кардан?**
Аутентификатсия/авторизатсия дар ҳар эндпоинт, rate limiting, валидатсияи вуруд, кам кардани додаҳо дар ҷавоб, HTTPS, санҷиши ҳуқуқ ба объект (зидди IDOR/BOLA).

**78. Shift left чист?**
Кӯчонидани санҷишҳои амният ба марҳилаҳои барвақтии таҳия (дар IDE ва CI), на танҳо пеш аз релиз. Барвақт ислоҳ кардан арзонтар аст.

## Треки Cloud

**79. IAM чист ва чаро нақшҳо аз калидҳо беҳтаранд?**
Идораи дастрасӣ дар абр. Нақшҳо креденшелҳои муваққатиро худкор медиҳанд, калидҳо — дарозумр ва аксар вақт ба код/логҳо мерезанд.

**80. Бакети S3 аз рӯи хато чӣ тавр оммавӣ мешавад?**
ACL-и оммавӣ, bucket policy бо `Principal: *`, Block Public Access-и хомӯшшуда. Сабаби классикии ихроҷҳо.

**81. `iam:PassRole` чист ва чаро хатарнок?**
Ҳуқуқи супоридани нақш ба хидмат. Дар пайванд бо сохтани захираҳо имкон медиҳад имтиёзҳоро то нақши тавонотар баланд бардорад.

**82. Ҳамларо дар AWS чӣ тавр ошкор кардан?**
CloudTrail (логҳои даъватҳои API), GuardDuty (детекти аномалияҳо), Config (тағйироти конфигуратсияҳо). Масалан сохтани калиди/нақши нав, даъватҳо аз минтақаи ғайриодӣ.

**83. Container escape чист?**
Баромадан аз контейнер ба хост. Сабабҳо: `--privileged`, монтажи `docker.sock`, hostPath, capabilities-и зиёдатӣ.

**84. Чаро Kubernetes Secret анбори бехатар нест?**
Ба таври пешфарз ин танҳо base64 (на рамзгузорӣ). Encryption at rest, маҳдудкунии RBAC, анборҳои берунии сирҳо лозиманд.

**85. RBAC дар Kubernetes чист?**
Назорати дастрасии ролӣ: Role/ClusterRole + Binding + ServiceAccount. Ҳуқуқи зиёдатии ServiceAccount → роҳ ба забти кластер.

## Треки DevSecOps

**86. Дар CI/CD pipeline чиро аз нигоҳи амният месанҷидӣ?**
SAST (Semgrep/CodeQL), SCA-и вобастагиҳо (Trivy/Snyk), secret scanning (gitleaks), сканкунии образҳо, сканкунии IaC, quality gate дар ёфтаҳои критикӣ.

**87. Чаро `git rm` сирро нест намекунад?**
Файл дар таърихи коммитҳо мемонад. Таърихро тоза кардан лозим (git filter-repo/BFG) ВА — ҳатман — худи сирро ротатсия кардан (он аллакай компрометатсияшуда).

**88. Secret scanning чист?**
Ҷустуҷӯи калидҳо/паролҳои ихроҷшуда дар код ва таърихи git (gitleaks, TruffleHog, GitHub Secret Scanning).

**89. Сирҳоро чӣ тавр бехатар идора кардан?**
Анборҳои сирҳо (Vault, cloud secrets manager), инъексия дар рантайм, на дар код/образ/env-файлҳо дар репо, ротатсия, камтарин имтиёз.

**90. IaC security чист?**
Санҷиши инфрасохтор-ҳамчун-код (Terraform) аз нигоҳи мисконфигҳо то татбиқ (Checkov, tfsec, KICS).

## AI Security

**91. Prompt injection чист?**
Ворид кардани дастурҳо ба вуруд/додаҳои LLM, ки рафтори онро аз нав муайян мекунанд. «SQLi барои LLM». Пурра ҳал намешавад, танҳо кам мешавад.

**92. Direct vs indirect prompt injection?**
Direct — ҳамлакунанда худаш промпти зарароварро ворид мекунад. Indirect — дастури зараровар дар додаҳое пинҳон аст, ки LLM мехонад (саҳифаи веб, ҳуҷҷат, нома).

**93. OWASP Top 10 for LLM (мисолҳо)?**
Prompt Injection, Insecure Output Handling, Training Data Poisoning, Excessive Agency, Sensitive Info Disclosure ва ғ.

**94. Excessive agency чист?**
Ба AI-агент ҳуқуқ/асбобҳои хеле зиёд; дар пайванд бо prompt injection ӯ амалҳои хатарнок иҷро мекунад (нест кардани додаҳо, ихроҷи сирҳо).

**95. Чаро insecure output handling дар LLM хатарнок аст?**
Баромади модел ба HTML/SQL/shell бе санитизатсия меафтад → XSS/SQLi/RCE-и классикӣ тавассути ҷавоби модел.

**96. MCP чист ва хатарҳояш?**
Model Context Protocol — стандарти пайваст кардани асбобҳо ба LLM. Хатарҳо: tool injection, гузаштан аз permission model, ихроҷи сирҳо, SSRF/path traversal тавассути параметрҳои асбобҳо.

## Саволҳои рафторӣ

**97. Чаро амнияти киберӣ?**
[Ҳикояи ростқавлонаи ту. Бо шавқ ба он ки ҳама чиз чӣ тавр сохта шудааст ва мешиканад, ва бо кори иҷрошуда пайваст кун — портфолиоро нишон деҳ.]

**98. Чӣ тавр навигариҳои ИБ-ро пайгирӣ мекунӣ?**
Habr (ҳаби ИБ), каналҳои профилии Telegram, ҷамоати security дар Twitter/X, таҳлили CVE, write-up-ҳо, HackerOne disclosed.

**99. Дар бораи лоиҳа/мошине ки бо он ифтихор мекунӣ нақл кун. (методи STAR)**
Situation → Task → Action → Result. «Мушкил → ман чӣ кардам → натиҷа». 2–3 чунин ҳикояро пешакӣ тайёр кун.

**100. Чӣ кор кардан, агар дар интервюи техникӣ ҷавобро надонӣ?**
Ростқавлона гуфтан, ки бархӯрд накардаӣ, вале баланд мулоҳиза кардан: чӣ тавр наздик мешудӣ, чиро гугл мекардӣ, ба чӣ монанд аст. Ростқавлӣ + усули тафаккур аз бофта арзишмандтар аст.

**101. Ҷонибҳои сусти ту?**
Камбудии воқеиро номбар кун + он чи барои беҳтаркунӣ мекунӣ. На «ман перфексионист».

**102. Дар прод осебпазирии критикии берун аз scope ёфтӣ. Амалҳо?**
Амиқтар эксплуатация накардан, PoC-и ҳадди ақалро сабт кардан, фавран ба соҳиб/аз рӯи барнома хабар додан, ба таври оммавӣ ошкор накардан. Ахлоқ ва қонуният пеш аз ҳама.
