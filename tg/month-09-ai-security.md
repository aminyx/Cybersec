**Мақсади моҳ:** азхудкунии гармтарин ва камёбтарин маҳорати солҳои 2026–2027 — амнияти системаҳои AI. ## Ҳафтаи 33 — LLM чӣ тавр кор мекунад ва ҷойҳои сусташ куҷост

### Рӯзи 241 — Асосҳои LLM барои мутахассиси амният
- 📺 **Назария (2 соат):** Моделҳои калони забонӣ чӣ тавр кор мекунанд. Токенҳо, контекст, промпт, temperature, галлюцинацияҳо. [Prompt Engineering Guide](https://www.promptingguide.ai/).
- 💻 **Амалия (1,5 соат):** Бо ягон LLM бозӣ кун: бифаҳм, ки system prompt, user prompt, context window чист.
- ✍️ **Супориш:** шарҳ деҳ, чаро LLM «фарқ намекунад» дастур аз додаҳоро — ин решаи аксари ҳамлаҳо аст.
- 🎯 **Худро санҷ:** context window чист ва чаро барои амният муҳим аст?

### Рӯзи 242 — OWASP Top 10 for LLM
- 📺 **Назария (2 соат):** [OWASP Top 10 for LLM](https://owasp.org/www-project-top-10-for-large-language-model-applications/) — ҳамаи 10-ро таҳлил кун: Prompt Injection, Insecure Output Handling, Training Data Poisoning, Model DoS, Supply Chain, Sensitive Info Disclosure, Insecure Plugin Design, Excessive Agency, Overreliance, Model Theft.

## Ҳафтаи 34 — Ҳамлаҳо ба барномаҳои LLM

### Рӯзи 248 — Indirect Prompt Injection
- 📺 **Назария (1,5 соат):** ҳамла тавассути додаҳое ки LLM мехонад (саҳифаи веб, нома, ҳуҷҷат, тикет). Классика: дастури пинҳонӣ дар сайте ки AI-агент онро ҷамъбаст мекунад.
- 💻 **Амалия (2,5 соат):** Моделсозӣ кун: дастури пинҳониро дар «ҳуҷҷат» гузор, онро ба LLM барои коркард деҳ, бубин, ки чӣ тавр рафторро мегирад.
- ✍️ **Супориш:** PoC-и инъексияи ғайримустақим тавассути контенти берунӣ.
- 🎯 **Худро санҷ:** чаро indirect injection аз direct барои AI-агентҳо хатарноктар аст?

### Рӯзи 249 — System Prompt Extraction & Leakage
- 📺 **Назария (1,5 соат):** ихроҷи промпти системавӣ, ихроҷи додаҳои ҳассос аз контекст.
- 💻 **Амалия (2,5 соат):** Дар чат-боти таълимӣ ба додани system prompt-и он бо усулҳои гуногун рас.
- ✍️ **Супориш:** 3 усули гуногуни кашидани system prompt.
- 🎯 **Худро санҷ:** ихроҷи system prompt чаро хатарнок аст?

### Рӯзи 250 — Jailbreak
- 📺 **Назария (1,5 соат):** усулҳои гузаштан аз маҳдудиятҳои модел (роль-плей, кодиронӣ, тақсим ва ғ.) — **танҳо барои санҷиши қонунии ҳифзҳо**.
- 💻 **Амалия (2,5 соат):** Дар обёртаи LLM-и таълимии худ устувории guardrails-ро ба гузаштанҳо санҷ.
- ✍️ **Супориш:** таснифи усулҳои jailbreak бо мисоли ҳифз аз ҳар як.
- 🎯 **Худро санҷ:** guardrails чӣ тавр jailbreak-ро гирифтан мехоҳанд ва чаро ин мусобиқаи зиреҳ ва тир аст?

### Рӯзи 251 — Insecure Output Handling
- 📺 **Назария (1,5 соат):** барориши LLM ба HTML/SQL/shell меафтад → XSS/SQLi/RCE-и классикӣ тавассути ҷавоби модел. Моҳи 3-и ту бо AI вомехӯрад.
- 💻 **Амалия (2,5 соат):** Моделсозӣ кун: LLM ҷавобе ме­созад, ки барнома онро беэҳтиётона ба саҳифа мегузорад → XSS.
- ✍️ **Супориш:** PoC-и XSS тавассути коркарди нобехатари барориши LLM.
- 🎯 **Худро санҷ:** чаро барориши LLM-ро ҳамчун бехатар бовар кардан мумкин нест?

### Рӯзи 252 — RAG ва Vector DB Security
- 📺 **Назария (1,5 соат):** [RAG (Retrieval-Augmented Generation)](https://www.youtube.com/results?search_query=rag+retrieval+augmented+generation+простыми+словами), пойгоҳҳои векторӣ, embedding. Ҳамлаҳо: заҳролудкунии пойгоҳи дониш, инъексия тавассути ҳуҷҷатҳо, ихроҷи додаҳо байни корбарон.
- 💻 **Амалия (2,5 соат):** Меъмории RAG-ро таҳлил кун. Заҳролудкунии манбаъро моделсозӣ кун (indirect injection тавассути ҳуҷҷати индексшуда).
- ✍️ **Супориш:** шарҳ деҳ, чӣ тавр RAG-пойгоҳро «заҳролуд кардан».
- 🎯 **Худро санҷ:** дар система­и RAG нуқтаҳои нави ҳамла куҷо пайдо мешаванд?

### Рӯзи 253 — Data Poisoning ва Model Supply Chain
- 📺 **Назария (1,5 соат):** заҳролудкунии додаҳои таълимӣ, хатарҳои зеркашии моделҳо аз [Hugging Face](https://huggingface.co/), десериализатсияи нобехатари (pickle) моделҳо.

- 🎯 **Худро санҷ:** чаро `pickle`-модели аз Hugging Face эҳтимолан хатарнок аст?

### Рӯзи 254 — Такрори ҳафта

## Ҳафтаи 35 — MCP: амнияти агентҳо ва асбобҳо

### Рӯзи 255 — MCP ва Tool Calling чист
- 📺 **Назария (2 соат):** [Model Context Protocol](https://modelcontextprotocol.io/) — чӣ тавр LLM ба асбобҳо ва додаҳо пайваст мешавад. Tool calling / function calling: модел функсияҳои беруниро даъват мекунад. Ин ҳамон чизест, ки чат-ботро ба **агент**-и дар ҷаҳони воқеӣ амалкунанда табдил медиҳад.
- 💻 **Амалия (1,5 соат):** Спецификатсияи MCP-ро таҳлил кун: server, client, tools, resources, prompts.
- ✍️ **Супориш:** нақша: чӣ тавр LLM тавассути MCP ба асбобҳо дастрасӣ мегирад.
- 🎯 **Худро санҷ:** чаро агенти дорои асбобҳо аз чат-боти оддӣ хатарноктар аст?

### Рӯзи 256 — Модели таҳдиди MCP/агентҳо
- 📺 **Назария (1,5 соат):** хатарҳои нав: excessive agency (ҳуқуқи зиёд дар агент), tool injection, confused deputy, дастрасии агент ба сирҳо/файлҳо/шабака.
- 💻 **Амалия (2 соат):** Таҳлил кун, ки чӣ тавр prompt injection + дастрасӣ ба асбобҳо = агент амали зараровар иҷро мекунад (нест кардани файлҳо, ихроҷи додаҳо, дархост).
- ✍️ **Супориш:** модели таҳдид барои AI-агенти дорои 3 асбоб.
- 🎯 **Худро санҷ:** excessive agency чист ва чаро дар OWASP LLM Top 10 аст?

### Рӯзи 257 — MCP-сервери худро месозем
- 📺 **Назария (1 соат):** [MCP SDK](https://modelcontextprotocol.io/) (Python SDK ҳаст — забони ту).
- 💻 **Амалия (3 соат):** MCP-сервери содда дар Python бо як-ду асбоб нависон (масалан «хондани файл», «дархости HTTP»). Ба MCP-client пайваст кун.
- ✍️ **Супориш:** MCP-сервери корӣ дар GitHub.
- 🎯 **Худро санҷ:** мефаҳмӣ, ки чӣ тавр асбоб ба дасти модел меафтад?

### Рӯзи 258 — MCP-сервери худро мешиканем
- 📺 **Назария (1,5 соат):** tool injection, гузаштан аз permission model, ихроҷи сирҳо тавассути асбобҳо, path traversal / SSRF тавассути параметрҳои tool.
- 💻 **Амалия (2,5 соат):** Осебпазириҳоро дар **сервери худ** ёб: асбоби «хондани файл» → path traversal? Асбоби HTTP → SSRF? Сирҳо ба агент дастрасанд?
- ✍️ **Супориш:** ҳисоботи осебпазириҳои MCP-сервери худӣ.
- 🎯 **Худро санҷ:** кадом осебпазириҳои классикии веб дар асбобҳои MCP пайдо мешаванд?

### Рӯзи 259 — MCP-и бехатар: ҳифз
- 📺 **Назария (1,5 соат):** permission model, sandbox, token isolation, secrets management, OAuth барои MCP, human-in-the-loop тасдиқҳо, allow-list-и асбобҳо.
- 💻 **Амалия (2,5 соат):** MCP-сервери худро харден кун: валидатсияи параметрҳо, маҳдудкунии роҳҳо/хостҳо, ҷудокунии сирҳо, тасдиқи амалҳои хатарнок.
- ✍️ **Супориш:** «то/баъд» — MCP-сервери осебпазир ва бехатар.
- 🎯 **Худро санҷ:** 5 қоидаи MCP-сервери бехатарро ном бар.

### Рӯзи 260 — LLM Firewall ва Guardrails
- 📺 **Назария (1,5 соат):** қабатҳои ҳифз: филтрасияи input/output, [Rebuff](https://github.com/protectai/rebuff), [LLM Guard](https://github.com/protectai/llm-guard), [NeMo Guardrails](https://github.com/NVIDIA/NeMo-Guardrails), [Lakera](https://www.lakera.ai/).
- 💻 **Амалия (2 соат):** Guardrail-и кушода (LLM Guard)-ро ба барномаи таълимӣ пайваст кун, санҷ, ки prompt injection-ро мегирад.

- 🎯 **Худро санҷ:** чаро guardrails қабати зарурӣ, вале нокифоягии ҳифз аст?

### Рӯзи 261 — Такрори ҳафта
