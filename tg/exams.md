# Имтиҳонҳои амалӣ (ба монанди ширкатҳои воқеӣ)

6 имтиҳон, ки мусоҳибаҳои техникӣ ва супоришҳои санҷишии воқеиро тақлид мекунанд. **Худат, бе ишора**, бо таймер супор. Ҳар як бо **ҳисобот** тамом мешавад — маҳз ҳисоботҳо ба корфармо нишон медиҳанд, ки ту фикр карда метавонӣ, на танҳо асбобҳоро зер мезанӣ.

**Қоидаҳо:**
- Танҳо ҳадафҳои қонунӣ (ВМ-ҳои худат, платформаҳои таълимӣ).
- Таймер фаъол — супоришҳои воқеӣ бо вақт маҳдуданд.
- Натиҷа — на «root гирифтам», балки **ҳисобот**: чӣ ёфтӣ, чӣ тавр, чаро хатарнок аст, чӣ тавр ислоҳ кардан.
- Насупоридӣ — ҳеҷ гап нест. Таҳлил кун, дар куҷо банд шудӣ, тез кун, аз нав супор.

---

## 📝 Имтиҳони 1 — Linux (баъд аз моҳи 2)

**Сенария:** мошини Linux дода шудааст. Ту — pentester, вазифа — root гирифтан ва ҳисобот додан.

**Вазифаҳо:**
1. Иктишоф гузаронидан (nmap, перечисление хидматҳо).
2. Дастрасии аввалин гирифтан (foothold).
3. Имтиёзҳоро то root баланд бардоштан.
4. «Флагҳо»-ро ёфтан (user.txt, root.txt).

**Ҳисобот бояд дошта бошад:**
- Методология (қадамҳо аз рӯи тартиб)
- Осебпазириҳои ёфташуда
- Чӣ тавр имтиёзҳоро баланд бардоштӣ
- Скриншотҳо-далелҳо
- Тавсияҳо оид ба ҳифз

**Ҳадафро аз куҷо гирифтан:** мошини нави THM/VulnHub-и Easy, ки надидӣ.
**Вақт:** 3 соат.
**Баҳои гузариш:** root + ҳисоботи фаҳмо.

---

## 📝 Имтиҳони 2 — Web (баъд аз моҳи 3)

**Сенария:** барномаи веб барои санҷиш. Осебпазириҳоро ёб, исбот кун, ислоҳ пешниҳод кун.

**Вазифаҳо:**
1. **SQLi** ёфтан — додаҳоро аз БД гирифтан.
2. **XSS** ёфтан — reflected ё stored.
3. **IDOR** ёфтан — дастрасӣ ба додаҳои бегона.
4. **SSRF** ёфтан (агар бошад).
5. Барои ҳар як — PoC ва тавсия оид ба ислоҳ.

**Ҳисобот бояд дошта бошад:**
- Ҳар осебпазирӣ: тавсиф, қадамҳои такрор, PoC, CVSS, чӣ тавр ислоҳ кардан
- Афзалиятбандӣ аз рӯи критикӣ

**Ҳадафро аз куҷо гирифтан:** [OWASP Juice Shop](https://github.com/juice-shop/juice-shop), DVWA дар High, ё мошини ношиноси веби THM.
**Вақт:** 4 соат.
**Баҳои гузариш:** ҳадди ақал 3 осебпазирӣ бо PoC ва тавсияҳо.

---

## 📝 Имтиҳони 3 — Blue Team / Incident Response (баъд аз моҳи 5 ва 8)

**Сенария:** ҳодиса рух дод. Артефактҳо дода шудаанд. Тафтиш кун ва Incident Report нависон.

**Дода шудааст:** `pcap` (трафик) + `evtx` (Windows-логҳо) + `auth.log` + `syslog`.

**Вазифаҳо:**
1. Муайян кардан, ки чӣ рух дод (навъи ҳамла).
2. **IOC** ёфтан (IP, хешҳо, доменҳо, файлҳо).
3. Ҳамларо аз рӯи **MITRE ATT&CK** ҷобаҷо кардан.
4. Ба **Cyber Kill Chain** гузоштан.
5. (сатҳи моҳи 8) **Қоидаҳои детект** (Sigma) барои оянда пешниҳод кардан.

**Ҳисобот (Incident Report) бояд дошта бошад:**
- Timeline (хронологияи ҳамла)
- Рӯйхати IOC
- MITRE ATT&CK mapping
- Баҳои зарар / чӣ компрометатсия шуд
- Тавсияҳо + детектҳо

**Аз куҷо гирифтан:** [CyberDefenders](https://cyberdefenders.org/), [malware-traffic-analysis.net](https://www.malware-traffic-analysis.net/), LetsDefend.
**Вақт:** 4 соат.
**Баҳои гузариш:** ҳодиса дуруст муайян шуд + IOC + ATT&CK + ҳисобот.

---

## 📝 Имтиҳони 4 — Cloud / AWS (баъд аз моҳи 7)

**Сенария:** аккаунти AWS (таълимӣ) дода шудааст. Аудити амният гузарон.

**Вазифаҳо:**
1. **Бакети S3-и кушода** ва он чӣ дар он аст ёфтан.
2. **IAM-и нодуруст** (ҳуқуқи зиёдатӣ/хатарнок) ёфтан.
3. Роҳи **баланд бардоштани имтиёзҳо** дар IAM ёфтан.
4. Санҷидан, ки чӣ тавр ин амалҳоро ошкор кардан (CloudTrail).

**Ҳисобот бояд дошта бошад:**
- Ҳар мисконфиг: хатар, далел, чӣ тавр ислоҳ кардан
- Занҷири IAM privesc
- Тавсияҳо оид ба мониторинг (CloudTrail/GuardDuty)

**Аз куҷо гирифтан:** [flaws.cloud](http://flaws.cloud/), [flaws2.cloud](http://flaws2.cloud/), [CloudGoat](https://github.com/RhinoSecurityLabs/cloudgoat).
**Вақт:** 4 соат.
**Баҳои гузариш:** S3 + IAM-мушкилот + privesc + ҳисобот ёфта шуд.

---

## 📝 Имтиҳони 5 — Kubernetes (баъд аз моҳи 7)

**Сенария:** дастрасӣ ба namespace дар кластер дода шудааст. Кластерро забт кун ва ҳисобот деҳ.

**Вазифаҳо:**
1. Иктишофи кластер аз pod.
2. **Secret** гирифтан.
3. **RBAC**-мисконфиг ёфтан → баланд бардоштани имтиёзҳо.
4. **Container/pod escape**-ро дар node иҷро кардан.
5. То назорати кластер расидан.

**Ҳисобот бояд дошта бошад:**
- Занҷири «pod → namespace → cluster»
- Ҳар қадам бо далел
- Тавсияҳо (RBAC, Pod Security, Network Policy, Falco)

**Аз куҷо гирифтан:** [Kubernetes Goat](https://madhuakula.com/kubernetes-goat/).
**Вақт:** 4 соат.
**Баҳои гузариш:** escape + забт + ҳисобот бо тавсияҳо.

---

## 📝 Имтиҳони 6 — AI / LLM Security (баъд аз моҳи 9)

**Сенария:** чат-боти дорои дастрасӣ ба асбобҳо (MCP/tool calling) дода шудааст. Амнияташро санҷ.

**Вазифаҳо:**
1. Ҳифзи промптро гузаштан (**prompt injection**).
2. **Prompt leak** ёфтан (system prompt-ро кашидан).
3. **Tool injection** ёфтан (маҷбур кардани агент ба суиистифодаи асбоб).
4. **Insecure output handling** санҷидан (XSS/инъексия тавассути барориш).
5. Ислоҳҳо пешниҳод кардан (guardrails, permission model, валидатсия).

**Ҳисобот бояд дошта бошад:**
- Ҳар ёфта: усул, PoC, хатар (OWASP LLM / MITRE ATLAS), ислоҳ
- Тавсияҳо оид ба ҳифзи AI-агент

**Аз куҷо гирифтан:** [Gandalf](https://gandalf.lakera.ai/), [PortSwigger LLM labs](https://portswigger.net/web-security/llm-attacks), MCP-сервери осебпазири худ аз моҳи 9.
**Вақт:** 4 соат.
**Баҳои гузариш:** prompt injection + leak + tool injection + ҳисобот бо ислоҳҳо.

## 🎯 Чӣ тавр аз имтиҳонҳо истифода бурдан

- **Баъд аз** моҳи мувофиқ супор (дар қавс нишон дода шудааст).
- Ҳамаи ҳисоботҳоро дар репозиторийи алоҳидаи GitHub `security-exams` гузор — ин далели мустақими маҳорат барои корфармо аст.
- Ҳисобот аз «шикастан» муҳимтар аст: 80%-и арзиш дар он аст, ки чӣ тавр ёфтаро ва ислоҳашро шарҳ медиҳӣ.
- Насупоридӣ — ин ташхис аст, на ҳукм. Ҷойи сустро нависон, тез кун, аз нав супор.

> Дар мусоҳибаҳои воқеии ИБ аксар вақт маҳз чунин супоришҳо медиҳанд. Ин 6-ро гузаронда — ту ба мусоҳиба омода меоӣ, на бори аввал.
