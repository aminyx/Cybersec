# ❓ Проверки знаний

Тест на каждый из 270 дней курса. Это ответ на вопрос «а как понять, что я реально усвоил день, а не просто посмотрел видео?».

**Главное правило: день нельзя отметить пройденным, пока не сдан его тест.** На сайте кнопка «Отметить пройденным» заблокирована до правильного ответа.

---

## Как проходить

### На сайте (рекомендуется)
Откройте день — внизу карточки блок **«Проверка знаний»**. Выберите вариант:
- **верно** → показывается объяснение, день можно отметить пройденным;
- **неверно** → показывается разбор и кнопка «Попробовать снова» (попыток сколько угодно — цель обучение, а не оценка).

Сданные тесты хранятся в браузере (`localStorage`, ключ `csc.quiz`).

### Из терминала
```bash
python checks/quiz.py 1            # проверка за день 1
python checks/quiz.py 1-7          # за неделю
python checks/quiz.py --random 5   # 5 случайных вопросов (повторение)
python checks/quiz.py --stats      # прогресс
```
Результат сохраняется в `checks/.passed` (в `.gitignore`).

> Совет: раз в неделю прогоняйте `--random 10` по пройденным темам. Интервальное повторение работает лучше, чем однократный ответ.

---

## Формат файлов

Один файл на месяц: `month-01.json` … `month-09.json`.

```json
{"d":1,"q":"Вопрос?","o":["A","B","C","D"],"a":1,"e":"Объяснение, почему так."}
```

| Поле | Значение |
|---|---|
| `d` | номер дня (сквозной, 1–270) |
| `q` | вопрос |
| `o` | варианты ответа (обычно 4) |
| `a` | индекс верного варианта (с нуля) |
| `e` | объяснение — показывается при **любом** ответе |

Объяснение обязательно: неверный ответ должен учить, а не просто говорить «нет».

## Как добавить или изменить тест

1. Отредактируйте нужный `month-XX.json`.
2. Проверьте корректность:
   ```bash
   python scripts/check_repo.py
   ```
   Валидатор ловит дубли дней, повторяющиеся варианты, неверный индекс ответа, отсутствие объяснения и **перекос верных ответов на одну позицию**.
3. Если добавили много вопросов подряд — выровняйте позиции верных ответов:
   ```bash
   python scripts/shuffle_checks.py --dry-run   # посмотреть
   python scripts/shuffle_checks.py             # применить
   ```
4. Пересоберите данные сайта:
   ```bash
   python site/build-data.py
   ```

### Почему важно перемешивать

При ручном написании верный ответ почти всегда оказывается на одной позиции. В первой версии этого курса **259 из 270** верных ответов стояли на позиции B — студент заметил бы паттерн и жал бы B не думая. Скрипт `shuffle_checks.py` детерминированно сдвигает варианты и выравнивает распределение.

## Принципы хороших вопросов

1. **Проверяют понимание, а не память.** Не «какой ключ у nmap», а «почему `-sS` тише, чем `-sT`».
2. **Правдоподобные неверные варианты.** Если три из четырёх — очевидная чушь, тест не работает.
3. **Объяснение учит.** После ответа студент должен знать больше, чем до.
4. **Один вопрос — одна идея.** Ключевая мысль дня, а не мелкая деталь.
5. **Проверка легальности.** Для дней про атаки часть вопросов намеренно касается границ закона — это тоже навык.
