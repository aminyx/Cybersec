# 🌐 Сайт курса

Статический сайт: дорожная карта, карточки месяцев, все 270 дней, поиск, трекинг прогресса и достижения. Двуязычный (RU/TJ), тёмная терминальная тема.

Без сборки, без зависимостей, без бэкенда — три файла и данные.

---

## Запуск локально

```bash
python -m http.server 8129 --directory site
```

Открой http://localhost:8129

> Через `file://` не заработает (браузер заблокирует загрузку `data.js`) — нужен любой локальный сервер.

---

## Обновление данных

Сайт **не дублирует** содержание курса — он читает его из markdown-файлов.
После правки любого `ru/month-*.md` или `tg/month-*.md` пересобери данные:

```bash
python site/build-data.py
```

Скрипт разберёт все 9 месяцев на двух языках и перезапишет `site/data-ru.js`, `site/data-tg.js` и `site/data-index.js`. Сайт грузит только тот язык, который выбрал студент.

---

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | Разметка |
| `styles.css` | Стили (CSS-переменные, тёмная тема) |
| `app.js` | Логика: i18n, поиск, прогресс, достижения |
| `data.js` | **Автоген** — не редактируй руками |
| `build-data.py` | Генератор `data.js` из markdown |

## Возможности

- **Двуязычность** — переключатель RU/TJ меняет весь интерфейс и содержание курса
- **Поиск** — по клавише `/` или `Ctrl/Cmd+K`; ищет по названиям дней и содержанию, стрелки + Enter
- **Прогресс** — отметка пройденных дней, кольцо прогресса, полоса в шапке; хранится в `localStorage`
- **Достижения** — Bronze (30) → Silver (90) → Gold (180) → Diamond (270 + 6 экзаменов + 10 проектов)
- **Карта курса** — обе фазы с прогрессом по каждому месяцу
- **Карточка дня** — теория, практика, задание, самопроверка; навигация стрелками `←` `→`

Прогресс хранится только в браузере пользователя. Аккаунтов и сервера нет.

## Публикация на GitHub Pages

1. Залей репозиторий на GitHub.
2. Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`.
3. Сайт будет доступен по `https://<username>.github.io/<repo>/site/`.

Чтобы сайт открывался в корне, перенеси содержимое `site/` в корень репозитория (тогда в `build-data.py` поправь `OUT` на нужный путь) или добавь workflow, который публикует только папку `site`.

## Доступность

Проверено: контраст текста 7.7–18:1 (WCAG AAA), все интерактивные элементы ≥44×44px, видимые focus-состояния, `prefers-reduced-motion`, отсутствие горизонтальной прокрутки на 375px, семантические заголовки и aria-подписи у иконочных кнопок.
