# 💬 Сообщество курса — как настроить

Живое сообщество снижает процент бросивших курс в разы: есть где спросить, с кем решать лабы, кому показать write-up. Сервер/канал создаёшь **ты** (нужен твой аккаунт) — этот файл даёт готовую структуру, правила и тексты, чтобы не начинать с нуля.

Рекомендация для аудитории RU/TJ/СНГ: **Telegram** (проще всего) или **Discord** (удобнее для тематических каналов и голоса). Ниже — обе схемы.

---

## Вариант A — Telegram

**Что создать:**
- **Канал** (анонсы, новые материалы) — односторонний.
- **Чат-супергруппу** с темами (topics) — двусторонний.

**Темы в чате:**
| Тема | Назначение |
|---|---|
| 📢 Правила и старт | Закреплённые правила, ссылка на курс |
| ❓ Вопросы | Любые вопросы по теории |
| 🧪 Помощь по лабам | THM/HTB/Codeby — без спойлеров-флагов |
| 🤝 Поиск команды | Собрать команду на CTF |
| 📝 Write-up и проекты | Публикация своих разборов |
| 💼 Вакансии и стажировки | Джун-позиции, стажировки |
| 🗣 Оффтоп | Общение |

**Настройки:** включи Topics, медленный режим (30–60 сек) против флуда, антиспам-бот (напр. Rose/Shieldy), запрет ссылок для новичков первые сутки.

## Вариант B — Discord

**Категории и каналы:**
```
━━ ИНФО ━━
  #правила            (только чтение)
  #старт-и-ссылки     (курс, roadmap, FAQ)
  #анонсы

━━ ОБУЧЕНИЕ ━━
  #вопросы-теория
  #помощь-по-лабам
  #месяцы-1-3   #месяцы-4-6   #месяцы-7-9
  #проекты-и-код

━━ CTF ━━
  #поиск-команды
  #weekly-challenge
  #write-ups

━━ КАРЬЕРА ━━
  #резюме-ревью
  #вакансии-и-стажировки

━━ ОБЩЕЕ ━━
  #оффтоп   #голосовой-1
```
**Роли:** `@Новичок`, `@Bronze/@Silver/@Gold/@Diamond` (по прогрессу — можно выдавать вручную или ботом), `@Ментор`, `@Модератор`.

## Правила сообщества (готовый текст — закрепи)

```
Добро пожаловать! Здесь мы учимся кибербезопасности вместе.

1. Уважение. Без токсичности, оскорблений, дискриминации.
2. Только легальное. Обсуждаем атаки ТОЛЬКО на учебных платформах и своих
   системах. Просьбы «взломать» реальную цель/аккаунт — бан.
3. Без спойлеров. Помогай наводящими вопросами, не выкладывай готовые флаги
   и полные решения активных заданий.
4. По теме. Технические вопросы — в профильные каналы, а не в оффтоп.
5. Ищешь помощь — покажи, что уже пробовал. «Не работает» без деталей игнорируется.
6. Не спамь, не рекламируй, не продавай курсы/услуги без разрешения.
7. Не делись пиратскими материалами. Все ресурсы курса — бесплатные и легальные.

Нарушение → предупреждение → мут → бан.
```

## Приветствие новичку (автосообщение)

```
👋 Привет! Рад видеть тебя в сообществе CyberSec Course.

С чего начать:
• Прочитай #правила
• Открой курс и roadmap: #старт-и-ссылки
• Застрял на дне — спрашивай в #вопросы-теория
• Нужна помощь по лабе — #помощь-по-лабам (без спойлеров!)

Представься: как тебя зовут, с какого дня начинаешь, куда целишься
(SOC / pentest / AppSec)? Погнали 🚀
```

## Как поддерживать живость

- **Weekly-challenge** по пятницам (см. [../challenges/README.md](../challenges/README.md)) — регулярный повод зайти.
- Отмечай прогресс участников: перешёл на новый ранг — поздравь публично.
- Раз в неделю — «вопрос дня» из [interview-questions.md](../ru/interview-questions.md).
- Поощряй write-up'ы: лучший за неделю — в закреп/анонс.
- Отвечай сам первые недели — тон общения задаёшь ты.
