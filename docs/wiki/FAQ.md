# FAQ (по проекту)

Вопросы про **сам проект/репозиторий**. Вопросы студента про обучение — в [ru/faq.md](../../ru/faq.md). Вопросы преподавателя — в [docs/teachers-faq.md](../teachers-faq.md).

### Нужно ли что-то устанавливать, чтобы просто читать курс?
Нет. Курс — это Markdown. Открывай [ru/](../../ru/README.md) или [tg/](../../tg/README.md) прямо на GitHub или в редакторе.

### Что нужно, чтобы запустить сайт?
Только Python (для сервера) и браузер. См. [Windows Setup](Windows-Setup.md) / [Linux Setup](Linux-Setup.md). Node.js не нужен.

### Почему сайт не открывается по двойному клику на index.html?
Через `file://` браузер блокирует загрузку `data.js`. Нужен локальный сервер:
```bash
python -m http.server 8129 --directory site
```

### Я поправил месяц в Markdown, а на сайте старое. Почему?
Сайт читает `site/data.js`, который **генерируется**. Пересобери:
```bash
python site/build-data.py
```

### Где хранится мой прогресс на сайте?
Только в твоём браузере (`localStorage`). Сервера и аккаунтов нет. Очистка данных браузера сбросит прогресс.

### Можно ли использовать проект коммерчески?
Да, проект под GPL-3.0 (см. [LICENSE](../../LICENSE)). Указывай авторство. Производные работы, которые ты распространяешь, тоже должны быть открыты под GPL-3.0.

### Как узнать актуальную статистику?
В [STATS.md](../../STATS.md), генерится `python scripts/build_stats.py`.

### Как предложить фичу?
Issue с меткой `roadmap`. Направление развития — в [ROADMAP.md](../../ROADMAP.md).

### Нашёл уязвимость в сайте/скриптах. Куда писать?
См. [SECURITY.md](../../SECURITY.md) — приватно, не публичным Issue.
