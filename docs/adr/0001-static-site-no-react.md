# ADR-0001: Сайт без React/фреймворка, статикой

**Статус:** Принято
**Дата:** 2026-07-29

## Контекст

Нужен сайт курса: карта, карточки месяцев, 270 дней, поиск, трекинг прогресса, достижения, двуязычность. Ограничения проекта:
- бесплатный хостинг;
- нулевой порог входа для студента (часто слабое железо, Windows);
- долгий срок жизни без «протухания» тулчейна;
- сопровождение силами одного человека / сообщества.

Варианты: React/Next.js (или Vue/Svelte) со сборкой; статический генератор (Astro/11ty); чистый HTML/CSS/JS без сборки.

## Решение

Пишем сайт на **чистом HTML + CSS + ванильном JS без сборочного шага и фреймворка**. Данные подгружаются из сгенерированного `data.js`. Хостинг — GitHub Pages (статика).

## Последствия

**Плюсы:**
- Ноль зависимостей и сборки: `git clone` → `python -m http.server` → работает.
- Не устаревает: нет npm-дерева, которое через год развалится на уязвимостях и мажорных обновлениях.
- Бесплатный статический хостинг, мгновенная загрузка.
- Любой может прочитать и поправить `app.js` без знания фреймворка.

**Минусы / компромиссы:**
- Нет «из коробки» роутинга, реактивности, компонентов — пишем руками.
- При росте сложности ванильный JS труднее структурировать, чем компонентный фреймворк.
- Нет типизации (TS) без добавления сборки.

**Что это закрывает на будущее:**
- Если понадобится сложное SPA (напр. AI Tutor с бэкендом) — это будет **отдельный модуль**, а не переписывание ядра. Ядро остаётся простым и статичным (см. [ROADMAP.md](../../ROADMAP.md)).
