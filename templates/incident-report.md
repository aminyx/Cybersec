**Новое правило детекта (Sigma)**

```yaml
title: Office spawns PowerShell with encoded command
id: [uuid]
status: experimental
description: Обнаруживает запуск PowerShell из офисного приложения с -enc
references:
  - INC-[ID]
logsource:
  product: windows
  category: process_creation
detection:
  selection:
    ParentImage|endswith:
      - '\WINWORD.EXE'
      - '\EXCEL.EXE'
    Image|endswith: '\powershell.exe'
    CommandLine|contains:
      - ' -enc'
      - ' -EncodedCommand'
  condition: selection
falsepositives:
  - Легитимные корпоративные макросы (проверить белый список)
level: high
```
