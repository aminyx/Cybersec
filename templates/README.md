# 📄 Шаблоны

Готовые шаблоны профессиональных документов. Копируй, заполняй `[поля]`, удаляй инструкции-цитаты. Именно такие документы отличают портфолио джуна от «прошёл курсы».

| Шаблон | Когда использовать | Месяц курса |
|---|---|---|
| [pentest-report.md](pentest-report.md) | Отчёт о пентесте (как у консалтинга) | 4, 9 |
| [incident-report.md](incident-report.md) | Расследование инцидента (SOC) | 5, 8 |
| [writeup.md](writeup.md) | Разбор машины/задачи для GitHub | со 2-го |
| [cve-report.md](cve-report.md) | Ответственное раскрытие / bug bounty | 3, 9 |
| [sigma-rule.yml](sigma-rule.yml) | Правило детекта атаки | 8 |
| [project-README.md](project-README.md) | README для Python-инструмента | 6, 8, 9 |

## Принципы хорошего документа

1. **Executive summary без жаргона** — начало читает руководитель, а не инженер.
2. **Факты со ссылкой на источник** — «Sysmon EID 1», а не «наверное, запустился процесс».
3. **Рекомендации конкретные** — «использовать prepared statements», а не «сделать безопасно».
4. **Риск для бизнеса ≠ CVSS** — критичность считай по влиянию на компанию.
5. **Только легально** — всегда фиксируй разрешение и область работ.

> Складывай заполненные документы в отдельные репозитории GitHub (`ctf-writeups`, `security-exams`). Это твоё портфолио.
