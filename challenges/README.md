# 🚩 Еженедельные CTF-челленджи

Небольшие задания на 10–20 минут с **автоматической проверкой** флага. Флаги хранятся только как SHA-256 — подсмотреть ответ в файлах нельзя, но проверить свой можно офлайн, без сервера и интернета.

Формат флага: `CSC{...}`

---

## Как решать

```bash
# список всех заданий и твой прогресс
python challenges/check.py

# показать конкретное задание с подсказками
python challenges/check.py w01-base64

# проверить флаг
python challenges/check.py w01-base64 "CSC{...}"

# сколько решено
python challenges/check.py --score
```

Подсказки открывай **по одной** и только когда реально застрял 10+ минут — смысл в том, чтобы додумать самому.

## Задания

| ID | Тема | Время | Доступно после |
|---|---|---|---|
| `w01-base64` | Кодирование ≠ шифрование | 10 мин | День 19 |
| `w02-caesar` | ROT13 / шифр сдвига | 10 мин | День 19 |
| `w03-hash-id` | Опознать и сломать хэш | 15 мин | День 16 |
| `w04-logs` | Найти брутфорс в auth.log | 20 мин | День 12 |
| `w05-http` | Инструмент сканирования в access.log | 20 мин | День 62 |

Артефакты (`sample-auth.log`, `access.log`) лежат рядом.

## Для сообщества

Выкладывай новый челлендж раз в неделю (например по пятницам) — это регулярный повод зайти в [сообщество](../docs/community-setup.md) и посоревноваться. Договорись не спойлить флаги в чате: помощь — только наводящими вопросами.

## Как добавить своё задание (для авторов)

1. Придумай флаг `CSC{...}` и посчитай хэш:
   ```bash
   python -c "import hashlib;print(hashlib.sha256('CSC{твой_флаг}'.encode()).hexdigest())"
   ```
2. Добавь объект в `challenges.json` (`id`, `title`, `task`, `hints`, `flag_sha256`).
3. Если нужен файл-артефакт — положи рядом и упомяни в `task`.
4. **Не коммить сам флаг** — только его SHA-256.
