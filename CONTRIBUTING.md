# 🤝 Как участвовать и партнёрская программа

Курс открытый. Его можно улучшать вместе: переводить, добавлять лаборатории, записывать видео, поддерживать актуальность. Этот файл — и обычный CONTRIBUTING, и **партнёрская программа для преподавателей/авторов**.

---

## Кто и что может добавлять

| Роль | Что делает |
|---|---|
| 🌍 **Переводчик** | Новые языки (уз, кырг, каз, англ.) или улучшение RU/TJ |
| 🧪 **Автор лабораторий** | Новые учебные стенды, docker-labs, CTF-задания |
| 🎥 **Видео-автор** | Записывает вступления к месяцам по сценариям |
| 🛠 **Мейнтейнер** | Обновляет ссылки, инструменты, версии под новый год |
| ✍️ **Ревьюер** | Проверяет корректность материалов, вычитывает тексты |

## Как внести правку (обычный поток)

1. Форкни репозиторий.
2. Создай ветку: `git checkout -b fix/month-3-links`.
3. Внеси изменения. После правки учебных файлов пересобери данные сайта:
   ```bash
   python site/build-data.py
   ```
4. Проверь ссылки и отправь Pull Request с понятным описанием.

**Стиль:** сохраняй структуру дня (📺 теория → 💻 практика → ✍️ задание → 🎯 проверь себя), тон (на «ты», дружелюбно, честно), только бесплатные и легальные ресурсы.

## 🌍 Партнёрская программа: перевод на новый язык

Полная структура одного языка (см. `tg/` как эталон):

```
<lang>/
  README.md, roadmap.md, faq.md, study-guide.md, student-pack.md, home-lab.md,
  month-01..09-*.md, exams.md, checklists.md, projects.md,
  after-course.md, certificate.md, advanced-course.md,
  glossary.md, resources.md, progress.md, _translation-status.md
```

**Правила перевода:**
1. **Технические термины оставляй на английском** + пояснение на языке (как в `glossary.md`). Не выдумывай несуществующие переводы для «prompt injection», «reverse shell» и т.п.
2. **Внутренние ссылки** веди на файлы своего языка; на другой язык — только для того, что ещё не переведено (пометь в `_translation-status.md`).
3. **Ничего не удаляй из структуры** — только переводи.
4. Начинай с входного набора + Месяца 1, дальше по порядку. Заявляй язык через Issue, чтобы не дублировать работу.
5. После завершения обнови корневой [README.md](README.md) (переключатель языков).

**Осторожно с генеративным переводом:** машинный перевод целиком без вычитки роняет качество. Переводи по файлу и вычитывай.

## 🧪 Партнёрская программа: новые лаборатории и задания

- Учебная цель = только **намеренно уязвимый** стенд, который автор имеет право распространять.
- Формат CTF-задания — см. [challenges/README.md](challenges/README.md): задание + захешированный флаг + подсказки.
- Docker-стенды клади в `docker-labs` с `docker-compose.yml` и README (одна команда запуска).
- **Никогда** не добавляй реальные эксплойты против конкретных живых систем или инструкции для незаконных действий.

## 🎥 Партнёрская программа: видео

- Сценарии готовы: [docs/video-scripts.md](docs/video-scripts.md).
- Формат: 10–15 мин вступление к месяцу (зачем, что будет, как не бросить).
- Заяви месяц через Issue, залей ссылку — добавим в карточку месяца на сайте.

## Поддержка версий (мейнтейнеры)

Раз в год проверяй:
- живы ли ссылки (ресурсы, платформы, инструменты);
- актуальны ли версии инструментов и облачных сервисов;
- не появились ли новые важные темы (обновляй Фазу 2).

Помечай крупные обновления тегом версии курса.

## Лицензия вклада

Отправляя Pull Request, ты соглашаешься, что твой вклад распространяется под [GPL-3.0](LICENSE) — той же лицензией, что и весь проект.

## Кодекс поведения

Уважение, инклюзивность, ноль токсичности. Всё, что добавляется, — **легально и этично**: только учебные цели, только с разрешением. Материалы, облегчающие реальные преступления, отклоняются.
